**In formulas.ts**, add these functions AFTER the existing `getRequiredComponents` function:

1. `calculateCategorySGP(statValue: number, allPlayerValues: number[]): number` — SGP = (statValue - mean) / stdDev. Takes a single stat value and the array of all player values at that stat to compute standard deviation. Returns how many standings gains this value provides.

2. `calculateTotalSGP(projection: StatComponents, allProjections: StatComponents[], categories: Category[]): number` — For each category, calculate SGP. For COUNTING stats, use the raw stat value. For RATE stats, use the rate calculated from components via existing formula functions. Sum all category SGPs. Handle LOWER_BETTER categories by negating before computing (lower ERA = higher SGP).

3. `getReplacementLevel(position: string, rosterSlots: Record<string, number>, totalTeams: number): number` — Returns the index (1-based) of the replacement player at a position. For exact-match slots (e.g., "C"), count = slots * teams. For shared slots ("UTIL"), prorate by 0.2 per team. For "IF"/"MI", prorate by 0.25. For "OF"/"CI", prorate by 0.33. Return Math.ceil(count) + 1.

4. `calculateVBD(playerSGP: number, replacementSGP: number): number` — Simply `playerSGP - replacementSGP`. Players below replacement return 0.

5. `calculateAuctionDollarValue(vbd: number, totalVBD: number, spendingPool: number, minBid: number): number` — Dollar value = (vbd / totalVBD) * spendingPool + minBid. Round to nearest integer. Never below minBid.

6. `calculateSpendingPool(budget: number, totalTeams: number, rosterSize: number, minBid: number): number` — Total auction dollars minus minimum bids for all roster spots: (budget * totalTeams) - (minBid * rosterSize * totalTeams).

**Important math notes:**
- Standard deviation uses population stddev (divide by N, not N-1) since we have all players
- For RATE stat SGP, compute the rate from components (use existing calculateAVG/ERA/etc), then compute SGP from those rates
- For LOWER_BETTER categories (ERA, WHIP), invert so lower values produce higher SGP: use `mean - statValue` instead of `statValue - mean`

Export all new functions from formulas.ts. Add new types to the barrel export in packages/shared/src/index.ts if one exists, or just ensure they're exported from types.ts.

**DraftRankingsAgent** (`packages/backend/src/agents/draft-rankings.ts`):

```typescript
export class DraftRankingsAgent {
  constructor(
    private db: Kysely<Database>,
    private logger?: Logger,
  ) {}

  async getRankings(
    leagueId: number,
    options?: {
      projectionsRunId?: number;
      limit?: number; // Default 300
      position?: string; // Filter by position
    }
  ): Promise<DraftRanking[]>
}
```

Implementation:
1. Load league settings from `league_settings_version` (get latest version for leagueId). Extract categories, roster_slots, totalTeams from settings_json.
2. Load player projections from `player_projection` joined with `player` table. If `projectionsRunId` provided, use that run; otherwise get latest "fresh" `projections_run`. Include player name, positions, and stat_components_json.
3. Group players by position. For each position, sort by total SGP descending.
4. Calculate replacement level per position using `getReplacementLevel()`.
5. For each position, the replacement player is the one at index `replacementLevel - 1` in the sorted list.
6. Calculate VBD for every player: `calculateVBD(playerSGP, replacementSGP)`. Use the maximum VBD across all eligible positions (multi-position players use their most valuable slot).
7. Sort all players by VBD descending. Assign tiers: top 10% = tier 1, next 15% = tier 2, next 25% = tier 3, rest = tier 4.
8. If `position` filter provided, filter results to only players eligible at that position.
9. Return top `limit` results as `DraftRanking[]`.

Log: total players loaded, projections run used, replacement levels per position, final ranking count.

7. Sort by dollarValue descending.
8. If `position` filter provided, filter results.

Log: total VBD, spending pool, number of players above/below replacement.
