  <action>
Create `packages/frontend/src/app/onboarding/page.tsx` as a "use client" component with a multi-step wizard. The page is protected by Next.js middleware (from Plan 02, requires accessToken cookie).

**Overall structure:**
- State: `currentStep` (0-3), `wizardContext` object to pass data between steps
- Progress bar at top showing 4 steps with filled/empty indicators
- Step content rendered based on currentStep
- Use Tailwind CSS, consistent with existing app styling (bg-gray-50, white cards, blue-600 primary)

**Step 0: Welcome** (canSkip: true)
- Headline: "Welcome to Fantasy Baseball Command Center"
- Brief value prop: "Get AI-powered recommendations for waivers, trades, and projected standings"
- Three bullet points: "Connect your ESPN league", "See projected final standings", "Get daily waiver and trade suggestions"
- "Get Started" button advances to step 1
- "Skip" link text below button also advances to step 1
- This step exists to set expectations, not to collect data

**Step 1: Connect League** (canSkip: false)
- Reuse the connect league form logic from the existing `/leagues/connect` page
- Fields: ESPN League ID (number input, required), Season (number, default 2026), league name (optional text)
- Private league toggle: when enabled, show SWID and espn_s2 fields with helper text explaining where to find them
- "Connect League" button: calls `api.connectLeague(...)`. On success, store the returned league in wizardContext and advance to step 2. On error, show error message inline.
- Loading state on the button during API call

**Step 2: Select Team** (canSkip: false)
- Fetch teams for the connected league using `api.getTeams(wizardContext.league.id)`
- Show list of teams as selectable cards (team name, abbreviation)
- User clicks a team to select it
- Store selected teamId in localStorage key `league_${leagueId}_team` (existing pattern from Phase 1)
- "Continue" button advances to step 3 (disabled until team selected)
- If league has only 1 team, auto-select and show confirmation instead of picker

**Step 3: Complete**
- Success message: "You're all set!"
- Summary: "Connected to [league name] as [team name]"
- Mention: "Upload FanGraphs projections from your league dashboard for even better recommendations"
- "Go to Dashboard" button: navigates to `/leagues/${wizardContext.league.id}`

**Error handling:**
- Each step that makes API calls shows inline error messages
- Network failures show retry button
- If user navigates away and comes back, restart from step 0 (state is in-memory only)

**Style notes:**
- Max-width container (max-w-2xl mx-auto) centered on page
- White card with shadow for each step content
- Blue primary buttons, gray secondary/skip actions
- Consistent with the existing login/signup page aesthetics
