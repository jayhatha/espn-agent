# Phase 89 Plan 01: ESPN Adapter Decomposition

## Goal

Split `packages/backend/src/adapters/espn.ts` into focused sub-modules with a thin facade that preserves all existing caller imports unchanged.

---

## Tasks

### Task 1: Extract constants, types, and validator

**Files:**

- `packages/backend/src/adapters/espn/constants.ts` _(create)_
- `packages/backend/src/adapters/espn/types.ts` _(create)_
- `packages/backend/src/adapters/espn/validator.ts` _(create)_

**What:**

**`constants.ts`** — Move all 7 constant maps here. None are exported from the facade. All are `export const` so sub-modules can import them:

- `ESPN_STAT_MAP` (lines 166–222 of espn.ts)
- `ESPN_LINEUP_SLOT_MAP` (lines 224–228)
- `ESPN_POSITION_MAP` (lines 230–250, currently unexported)
- `ESPN_PRO_TEAM_MAP` (lines 252–261, currently unexported)
- `ESPN_POSITION_TO_SLOT` (lines 263–268, currently unexported)
- `ALL_POSITION_SLOT_IDS` (line 271, currently unexported)
- `ESPN_TRANSACTION_TYPE_MAP` (lines 273–279, currently unexported)

**`types.ts`** — Move all exported interfaces here:

- `ESPNAuthCookies`
- `ESPNFetchOptions`
- `ESPNRawResponse`
- `ESPNScoringCategory`
- `ESPNRosterEntry`
- `ESPNTeamData`
- `ESPNFreeAgent`
- `ESPNGlobalDraftPlayer`
- `ESPNTransactionItem`
- `ESPNTransaction`
- `ESPNLeagueData`

No imports other than built-ins. Types file has zero runtime dependencies.

**`validator.ts`** — Create `EspnResponseValidator` class. Constructor: `constructor(private logger?: BaseLogger)`. Owns the two fingerprinting methods extracted from `ESPNAdapter`:

- `computeSchemaFingerprint(data: Record<string, unknown>): string` — sha256 of `extractStructure(data)`, returns first 16 hex chars
- `extractStructure(obj: unknown, depth = 0): unknown` — recursive structure extractor, bails at depth > 3

The three schema-validation functions (`validateEspnResponse`, `assertEspnCriticalShape`, `logUnexpectedFields`) remain in `../utils/espn-schemas.js` — `EspnResponseValidator` does NOT re-implement or wrap them. The class is pure: no HTTP, no cache, no constants.

**Verify:** `tsc --noEmit` on these three files passes with zero errors. Each file is importable in isolation.

### Task 2: Create EspnDataNormalizer and EspnHttpClient

**Files:**

- `packages/backend/src/adapters/espn/normalizer.ts` _(create)_
- `packages/backend/src/adapters/espn/http-client.ts` _(create)_

**What:**

**`normalizer.ts`** — Create `EspnDataNormalizer` class. Constructor: `constructor(private logger?: BaseLogger)`. Imports constants from `./constants.js` and types from `./types.js`. No HTTP dependencies. Contains:

- `normalizeLeagueData(raw: Record<string, unknown>): ESPNLeagueData` — full implementation from `ESPNAdapter.normalizeLeagueData` (lines 1172–1280 of espn.ts). Uses `ESPN_STAT_MAP`, `ESPN_LINEUP_SLOT_MAP`, `ESPN_PRO_TEAM_MAP` from constants.
- `parseFreeAgentsFromPlayers(raw: Record<string, unknown>)` — extracted from private method (lines 1283–1300). Uses `ESPN_POSITION_MAP`.
- `mapRosterSlotIds(slotCounts: Record<string, number>): Record<string, number>` — extracted from private method (lines 1320–1332). Uses `ESPN_LINEUP_SLOT_MAP`.

`EspnDataNormalizer` is instantiable without any mocking. Zero network calls.

**`http-client.ts`** — Create `EspnHttpClient` class. Constructor: `constructor(private logger?: BaseLogger)`. Owns all network, throttle, and cache concerns. Imports:

- `EspnResponseValidator` from `./validator.js` (for `computeSchemaFingerprint`)
- Types from `./types.js`
- Constants `ESPN_LINEUP_SLOT_MAP`, `ESPN_PRO_TEAM_MAP`, `ESPN_POSITION_TO_SLOT`, `ALL_POSITION_SLOT_IDS`, `ESPN_TRANSACTION_TYPE_MAP`, `ESPN_STAT_MAP` from `./constants.js`
- Schema validators from `../utils/espn-schemas.js`

Moves from `ESPNAdapter` into `EspnHttpClient`:

- Module-level `espnThrottle`, `lastEspnCall`, `throttledEspnCall` — keep as module-level in this file
- `private cache: LRUCache` — same 2000-slot config
- `private lastRequestTime` — instance-level for historical fetch throttle
- `private client: AxiosInstance` — same axios setup (baseURL, timeout, User-Agent, paramsSerializer)
- All public fetch methods: `fetchLeague`, `fetchFreeAgents`, `fetchHistoricalWeek`, `getFinalScoringPeriod`, `fetchTransactions`, `fetchPreDraftAuctionValues`, `fetchGlobalDraftData`
- Private helpers: `getCacheKey`, `getCached`, `setCache`, `clearCache`

`computeSchemaFingerprint` calls are replaced with `this.validator.computeSchemaFingerprint(...)` where `this.validator = new EspnResponseValidator(logger)` created in constructor.

**Verify:** `tsc --noEmit` on both files passes. `EspnDataNormalizer` can be imported and `new EspnDataNormalizer()` called with no arguments in a test file without errors.

### Task 3: Rewrite facade and update the two callers that import constants directly

**Files:**

- `packages/backend/src/adapters/espn.ts` _(rewrite)_
- `packages/backend/src/agents/player-pool-sync.ts` _(edit one import line)_
- `packages/backend/src/api/admin.ts` _(edit one import block)_

**What:**

**`adapters/espn.ts`** — Replace the entire 1200-line file with a thin facade (~60 lines):

```typescript
// Re-export all types for backward compatibility
export type {
  ESPNAuthCookies,
  ESPNFetchOptions,
  ESPNRawResponse,
  ESPNScoringCategory,
  ESPNRosterEntry,
  ESPNTeamData,
  ESPNFreeAgent,
  ESPNGlobalDraftPlayer,
  ESPNTransactionItem,
  ESPNTransaction,
  ESPNLeagueData,
} from "./espn/types.js";

import type { BaseLogger } from "pino";
import { EspnHttpClient } from "./espn/http-client.js";
import { EspnDataNormalizer } from "./espn/normalizer.js";
import { EspnResponseValidator } from "./espn/validator.js";
import type {
  ESPNAuthCookies,
  ESPNFetchOptions,
  ESPNRawResponse,
  ESPNFreeAgent,
  ESPNGlobalDraftPlayer,
  ESPNTransaction,
  ESPNLeagueData,
} from "./espn/types.js";

export class ESPNAdapter {
  private http: EspnHttpClient;
  private normalizer: EspnDataNormalizer;

  constructor(logger?: BaseLogger) {
    this.http = new EspnHttpClient(logger);
    this.normalizer = new EspnDataNormalizer(logger);
    new EspnResponseValidator(logger); // validator used internally by http-client
  }

  fetchLeague(options: ESPNFetchOptions): Promise<ESPNRawResponse> {
    return this.http.fetchLeague(options);
  }
  fetchFreeAgents(
    options: Parameters<EspnHttpClient["fetchFreeAgents"]>[0],
  ): Promise<ESPNFreeAgent[]> {
    return this.http.fetchFreeAgents(options);
  }
  fetchHistoricalWeek(
    options: Parameters<EspnHttpClient["fetchHistoricalWeek"]>[0],
  ): Promise<ESPNRawResponse> {
    return this.http.fetchHistoricalWeek(options);
  }
  getFinalScoringPeriod(season: number): Promise<number | undefined> {
    return this.http.getFinalScoringPeriod(season);
  }
  fetchTransactions(
    options: Parameters<EspnHttpClient["fetchTransactions"]>[0],
  ): Promise<ESPNTransaction[]> {
    return this.http.fetchTransactions(options);
  }
  fetchPreDraftAuctionValues(
    options: Parameters<EspnHttpClient["fetchPreDraftAuctionValues"]>[0],
  ) {
    return this.http.fetchPreDraftAuctionValues(options);
  }
  fetchGlobalDraftData(
    options: Parameters<EspnHttpClient["fetchGlobalDraftData"]>[0],
  ): Promise<ESPNGlobalDraftPlayer[]> {
    return this.http.fetchGlobalDraftData(options);
  }
  normalizeLeagueData(raw: Record<string, unknown>): ESPNLeagueData {
    return this.normalizer.normalizeLeagueData(raw);
  }
  clearCache(): void {
    this.http.clearCache();
  }
}
```

Note: `ESPN_STAT_MAP` and `ESPN_LINEUP_SLOT_MAP` are **not** re-exported from this facade (per goal criterion 5).
