<objective>
Add a season finalization system that prevents redundant recomputation of projected standings for completed seasons. When a season is finalized (either automatically after backfill or manually by admin), the SnapshotOrchestratorAgent skips the expensive computeProjectedStandings() call entirely.

Purpose: Backfill re-runs for 2024 and earlier seasons currently recompute projected standings from scratch even though the underlying data is immutable. This wastes compute time and risks overwriting correct historical projections.
Output: Migration 020, schema update, guard logic in snapshot orchestrator, auto-finalization in backfill agent, admin reset endpoint.
</objective>

**1. Add auto-finalization to `packages/backend/src/agents/historical-backfill.ts`:**

Add a private method `finalizeSeasonIfComplete` to the `HistoricalBackfillAgent` class:

```typescript
  /**
   * Mark a season as finalized after successful backfill completion.
   * Finalized seasons skip projection recomputation in SnapshotOrchestratorAgent.
   */
  private async finalizeSeasonIfComplete(
    leagueId: number,
    season: number,
    snapshotCount: number,
  ): Promise<void> {
    await this.db
      .insertInto("season_metadata")
      .values({
        league_id: leagueId,
        season,
        is_finalized: true,
        finalized_at: new Date(),
        snapshot_count: snapshotCount,
      })
      .onConflict((oc) =>
        oc.columns(["league_id", "season"]).doUpdateSet({
          is_finalized: true,
          finalized_at: new Date(),
          snapshot_count: snapshotCount,
        }),
      )
      .execute();

    this.logger?.info(
      { leagueId, season, snapshotCount },
      "Season finalized — future snapshot runs will skip projection recomputation",
    );
  }
```

```typescript
  // PUT /api/admin/seasons/:leagueId/:season/finalize - Set or reset season finalization
  app.put(
    "/api/admin/seasons/:leagueId/:season/finalize",
    { onRequest: [requireAdmin] },
    async (request: any, reply: any) => {
      const leagueId = parseInt(request.params.leagueId, 10);
      const season = parseInt(request.params.season, 10);
      const { finalized } = request.body as { finalized: boolean };

      if (isNaN(leagueId) || isNaN(season)) {
        return reply.status(400).send({ error: "Invalid leagueId or season" });
      }

      if (typeof finalized !== "boolean") {
        return reply.status(400).send({ error: "Body must include { finalized: boolean }" });
      }

      await db
        .insertInto("season_metadata")
        .values({
          league_id: leagueId,
          season,
          is_finalized: finalized,
          finalized_at: finalized ? new Date() : null,
          snapshot_count: null,
        })
        .onConflict((oc) =>
          oc.columns(["league_id", "season"]).doUpdateSet({
            is_finalized: finalized,
            finalized_at: finalized ? new Date() : null,
          }),
        )
        .execute();

      return {
        league_id: leagueId,
        season,
        is_finalized: finalized,
        message: finalized
          ? "Season finalized — projection recomputation will be skipped"
          : "Season un-finalized — projection recomputation will resume",
      };
    },
  );

  // GET /api/admin/seasons/:leagueId - List season metadata for a league
  app.get(
    "/api/admin/seasons/:leagueId",
    { onRequest: [requireAdmin] },
    async (request: any, reply: any) => {
      const leagueId = parseInt(request.params.leagueId, 10);

      if (isNaN(leagueId)) {
        return reply.status(400).send({ error: "Invalid leagueId" });
      }

      const seasons = await db
        .selectFrom("season_metadata")
        .selectAll()
        .where("league_id", "=", leagueId)
        .orderBy("season", "desc")
        .execute();

      return { seasons };
    },
  );
```
