**CategoryPaceBar.tsx** — A horizontal Tailwind progress bar component:

Props: `{ current: number; projected: number; statKey: string; type: "COUNTING" | "RATE" }`.

For COUNTING stats: progress = `(current / projected) * 100`. Bar is green (bg-positive) if progress >= season_progress_pct (approximate as current/projected >= 0.9 of expected pace), amber (bg-warning) if lagging. Show `current / projected` as the label.

For RATE stats: Don't show a fill bar (rates aren't cumulative). Instead show the current rate value and projected rate value side by side with an arrow between them, colored green if improving toward projected, amber if diverging.

Use `formatStatValue` from CategoryStatsTable for number formatting. Use dark: classes consistent with shell theme (dark:bg-shell-border for bar background track).

Height: h-2 rounded-full. Wrap in a flex row with a w-16 label.

**GapDetailRow.tsx** — An expandable table sub-row component:

Props: `{ categoryId: string; categoryName: string; myTeamId: number; allTeamValues: Array<{ teamId: number; teamName: string; value: number }>; direction: "HIGHER_BETTER" | "LOWER_BETTER"; numTeams: number; statType: string; statKey: string; isExpanded: boolean }`.

When `isExpanded` is true, renders a `<tr>` with a single `<td colSpan={full}>` containing:
- The team immediately above in rank: their name, value, and the gap (formatted with formatStatValue)
- My team: name, value (highlighted with accent color)
- The team immediately below: their name, value, and how much I lead by

Use `interpolateRotoPoints` from shared/formulas.ts to compute rankings from the raw values. Show rank numbers. Use `getRankColor` for rank styling.

When hidden (`!isExpanded`), renders null.

Style: dark:bg-shell-bg background, border-l-2 border-accent on the left, indented text, font-mono for numbers.
