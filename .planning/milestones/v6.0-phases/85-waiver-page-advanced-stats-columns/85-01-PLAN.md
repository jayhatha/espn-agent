# Plan 85-01 — Backend/API advanced-stats enrichment + waiver UI columns

## Goal

Add the requested hitter and pitcher advanced-stat columns to the waiver page manual-evaluation tables by enriching the existing free-agent and roster endpoints with advanced stats, then rendering sortable columns in the frontend.

## Tasks

### Task 1: Add backend advanced-stats adapter

**Files:**

- `packages/backend/src/adapters/advanced-stats.ts`

**Work:**

- Fetch Baseball Savant batter expected-stat CSV for `xBA`, `xSLG`, `xwOBA`
- Fetch Baseball Savant pitcher expected-stat CSV for `xERA`
- Cache lookup maps by season
- Derive `BABIP`, `ISO`, `K/9`, `K-BB%`, and `FIP` from existing ESPN component stats
- Return `null` for `xFIP` and `SIERA` when unavailable

### Task 2: Enrich waiver API responses

**File:**

- `packages/backend/src/api/recommendations.ts`

**Work:**

- Return `currentStats` on free-agent responses
- Add `advancedStats` to both free-agent and roster responses
- Reuse the new adapter for both endpoints

### Task 3: Render advanced stat columns in waiver manual-eval tables

**File:**

- `packages/frontend/src/app/leagues/[id]/waivers/page.tsx`

**Work:**

- Extend response types with `advancedStats`
- Feed advanced values into free-agent and roster row models
- Add sortable headers and cells for:
  - Hitters: `BABIP`, `xBA`, `xSLG`, `xwOBA`, `ISO`
  - Pitchers: `K-BB%`, `K/9`, `FIP`, `xFIP`, `xERA`, `SIERA`
- Add a small note explaining that unavailable public-source metrics render as `--`

## Acceptance Criteria

- [x] Free-agent endpoint returns `currentStats` and `advancedStats`
- [x] Roster endpoint returns `advancedStats`
- [x] Waiver free-agent table renders all requested hitter and pitcher advanced-stat headers
- [x] Waiver roster table renders the same advanced-stat headers
- [x] Unavailable metrics degrade to `--` instead of fabricated values
- [x] No TypeScript errors in modified backend/frontend files
