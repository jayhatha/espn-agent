# Plan 83-02 — Frontend: Changelog My-Team Filter + Standings Neighborhood

## Goal

Transform `changelog/page.tsx` into a focused my-team command center:

1. **Filter event feed to my team only** — remove other teams' events entirely (vs. current faded opacity)
2. **Add `StandingsNeighborhood` panel** — inline section showing overall roto standings for me + 2 above + 2 below, updated live after each poll
3. **Rewrite `EventCard` narrative to play-by-play style** — "Now 3rd in HR, passing [team]." derived from `curr_roto_pts` + `numTeams` (no schema change needed)

## Design Direction

From design context: data-forward, dense but organized. The neighborhood panel should feel like a focused scoreboard — not a card, more like a tight table/row cluster. Accent the user's row. Use `font-mono` for numbers. Keep it compact — it's context, not the main event.

## Context

- `ourTeamId` from localStorage key `league_${leagueId}_team`
- Category rank is derivable: `rank = numTeams - curr_roto_pts + 1` (since roto pts = `numTeams - rank + 1`)
- Passed team already in `event.passed_team_name` / `event.passed_team_id`
- `numTeams` from `teamsData?.teams.length`
- Neighborhood API: `GET /api/leagues/:leagueId/teams/:teamId/standings/neighborhood` (from 83-01)
- `api.ts` already has pattern for team-scoped endpoints

### Task 5: Rewrite `EventCard` with play-by-play narrative

The card should read like a telegram dispatch: what happened → where we stand now → who we passed.

New narrative structure (replaces team-name header + passed label + proximate cause block):

```tsx
function EventCard({
  event,
  teamName,
  numTeams,
}: {
  event: ChangeEvent;
  teamName: string;
  numTeams: number;
}) {
  const gained = event.direction === "gained";
  const catRank = Math.round(numTeams - event.curr_roto_pts + 1);
  const prevRank = Math.round(
    numTeams - (event.curr_roto_pts - event.roto_delta) + 1,
  );
  const rankChanged = catRank !== prevRank;

  const deltaStr = gained
    ? `+${Number(event.roto_delta).toFixed(1)}`
    : Number(event.roto_delta).toFixed(1);

  const formattedTime = new Date(event.occurred_at).toLocaleString("en-US", {
    month: "short",
    day: "numeric",
    hour: "numeric",
    minute: "2-digit",
    hour12: true,
  });

  // Build narrative lines
  const lines: string[] = [];

  // Line 1: what happened (from proximate cause)
  if (event.proximate_cause?.description) {
    lines.push(event.proximate_cause.description);
  }

  // Line 2: category rank movement
  const passedText =
    gained && event.passed_team_name
      ? `, passing ${event.passed_team_name}`
      : !gained && event.passed_team_name
        ? `, passed by ${event.passed_team_name}`
        : "";

  if (rankChanged) {
    lines.push(
      `Now ${ordinal(catRank)} in ${event.category_name}${passedText}.`,
    );
  } else if (passedText) {
    lines.push(`${ordinal(catRank)} in ${event.category_name}${passedText}.`);
  }

  return (
    <div
      className={cn(
        "border rounded-lg p-4 transition-colors",
        gained ? "border-positive/20" : "border-negative/20",
        "bg-surface-1",
      )}
    >
      <div className="flex items-start justify-between gap-3">
        {/* Left: icon + narrative */}
        <div className="flex items-start gap-3 min-w-0">
          <div
            className={cn(
              "mt-0.5 shrink-0 w-7 h-7 rounded-full flex items-center justify-center",
              gained
                ? "bg-positive/10 text-positive"
                : "bg-negative/10 text-negative",
            )}
          >
            {gained ? (
              <TrendingUp className="w-3.5 h-3.5" />
            ) : (
              <TrendingDown className="w-3.5 h-3.5" />
            )}
          </div>

          <div className="min-w-0">
            {/* Category badge */}
            <span
              className={cn(
                "inline-flex items-center px-1.5 py-0.5 rounded text-xs font-mono font-medium mb-1.5",
                gained
                  ? "bg-positive/10 text-positive"
                  : "bg-negative/10 text-negative",
              )}
            >
              {event.category_name}
            </span>

            {/* Narrative lines */}
            {lines.map((line, i) => (
              <p
                key={i}
                className={cn(
                  "text-sm",
                  i === 0 ? "text-content-primary" : "text-content-secondary",
                )}
              >
                {line}
              </p>
            ))}
          </div>
        </div>

        {/* Right: delta + time */}
        <div className="shrink-0 text-right">
          <span
            className={cn(
              "font-mono text-sm font-semibold",
              gained ? "text-positive" : "text-negative",
            )}
          >
            {deltaStr} pts
          </span>
          <p className="text-xs text-content-tertiary mt-0.5">
            {formattedTime}
          </p>
        </div>
      </div>
    </div>
  );
}
```

Add `ordinal` helper:

```typescript
function ordinal(n: number): string {
  const s = ["th", "st", "nd", "rd"];
  const v = n % 100;
  return n + (s[(v - 20) % 10] || s[v] || s[0]);
}
```

Pass `numTeams` from page: `<EventCard event={event} teamName={...} numTeams={teamsData?.teams.length ?? 10} />`

Remove `isOurTeam` prop since all rendered events are now for our team.
