## Decisions Made
- **Per-period accumulation only for backfill**: Kept existing writeCurrentStandings() unchanged for live snapshots to avoid regression risk. Historical backfill calls the new method.
- **Pitching component remapping at calculation time**: Instead of renaming components during accumulation, we remap HA->H and BBA->BB when building the components object for calculateFinalRate. This preserves raw component names in components_json.
- **Immediate OUTS-to-IP conversion**: Converted OUTS to IP during accumulation rather than at rate calculation time for consistency with other components.
- **League categories from settings**: Categories endpoint returns categories from league_settings_version rather than hardcoding, enabling dynamic category support.
