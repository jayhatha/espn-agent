   - Level variants from research: level 1 = "text-h1", level 2 = "text-h2", level 3 = "text-h3", level 4 = "text-h4"
   - Default tag = h{level} unless `as` prop overrides
   - Export both Heading and headingVariants

3. Create `Text.tsx` using CVA:
   - Props: extends React.HTMLAttributes<HTMLParagraphElement>, size?: "lg"|"base"|"sm"|"caption"|"data", color?: "default"|"secondary"|"tertiary", as?: "p"|"span"|"div"
   - Size variants: lg = "text-body-lg", base = "text-body", sm = "text-body-sm", caption = "text-caption", data = "text-data"
   - Color variants: default = "text-content", secondary = "text-content-secondary", tertiary = "text-content-tertiary"
   - Default tag = "p", default size = "base", default color = "default"

All three components must use cn() from @/lib/cn and accept className prop.

   - Base: "inline-flex items-center justify-center font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50"
   - Variants: primary (bg-accent text-content-inverse hover:bg-accent-hover), secondary (border border-neutral-300 bg-white), ghost (text-content-secondary hover:bg-accent-light), danger (bg-negative text-white)

   - Card: "rounded-card border border-neutral-200 bg-white shadow-card" + className via cn()
   - CardHeader: "px-6 py-4 border-b border-neutral-100"
   - CardContent: "px-6 py-4"
   - CardFooter: "px-6 py-4 border-t border-neutral-100"
   - All accept children and className

3. Create `Badge.tsx` using CVA:
   - Variants: default (bg-accent-light text-content), positive (bg-positive-light text-positive border-positive-border), negative (bg-negative-light text-negative border-negative-border), warning (bg-warning-light text-warning border-warning-border), info (bg-info-light text-info border-info-border)
   - Base: "inline-flex items-center rounded-full border px-2.5 py-0.5 text-xs font-medium"

4. Create `Input.tsx`:
   - Extends React.InputHTMLAttributes<HTMLInputElement>
   - Base: "flex h-10 w-full rounded-lg border border-neutral-300 bg-white px-3 py-2 text-body-sm text-content placeholder:text-content-tertiary focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-accent focus-visible:ring-offset-2 disabled:cursor-not-allowed disabled:opacity-50"
   - Use React.forwardRef for form library compatibility
   - Accept className via cn()

5. Create `Select.tsx`:
   - Same pattern as Input but for <select> element
   - Base styles matching Input with "appearance-none" and custom arrow via background-image or just browser default

6. Create `components/motion/FadeIn.tsx` (create the motion/ directory):

   - Hidden state: "opacity-0 translate-y-3"
   - Visible state: "opacity-100 translate-y-0"
   - transitionDelay via inline style
   - Disconnect observer after first intersection (one-time reveal)
