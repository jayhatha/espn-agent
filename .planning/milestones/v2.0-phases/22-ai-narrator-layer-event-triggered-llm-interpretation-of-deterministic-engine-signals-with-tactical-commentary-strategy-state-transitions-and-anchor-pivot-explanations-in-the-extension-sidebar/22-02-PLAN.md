   - Export `useNarratorStore`

<task type="auto">
  <name>Task 2: Create useNarrator hook with trigger logic, debounce, and session cap</name>
  <files>packages/extension/lib/use-narrator.ts</files>
  <action>
Create `packages/extension/lib/use-narrator.ts`:

1. Import dependencies:
   - `useEffect`, `useRef`, `useCallback` from "react"
   - `DraftEngineSignals` type from "./engine"
   - `useNarratorStore` from "./narrator-state"
   - `useDraftStore` from "./draft-state"
   - `NarratorPayload` from "./narrator-types"

2. Define constants:
   - `DEBOUNCE_MS = 1500`
   - `SESSION_CAP = 120`

3. Create `buildDedupeKey(signals: DraftEngineSignals, triggerReason: string): string`:
   - Concatenate: sorted alert IDs joined by comma + "|" + archetypeLabel or "null" + "|" + pacingStatus + "|" + triggerReason
   - Returns the concatenated string

4. Create `buildNarratorPayload(signals, triggerReason, context): NarratorPayload`:
   - `draftPhase`: derive from allPicks length (0-5 = "early", 6-15 = "mid", 16+ = "late") -- use context.allPicks or signals-derived pick count
   - Map engine signal fields to NarratorPayload fields:
     - alerts: signals.alerts (include type, severity, title, detail, position, category)
     - inflation: { percentOverMarket: signals.inflation.percentOverMarket, confidence: signals.inflation.confidence }
     - budgetSummary: from signals.budgetCurve (remainingBudget, pacingStatus, budgetPressure, maxBidRecommendation)
     - archetype: from signals.archetype (archetypeLabel, archetypeConfidence, puntedCategories from ceilings.filter(c => c.isPunted), pivotPlayers)
     - topScarcity: signals.scarcity (position, scarcityIndex, myTeamNeeds, supply, demand)
     - categoryGaps: signals.categoryGaps (category, gapZScore, categoryRiskScore)
     - currentAuctionPlayer: from context (playerName, currentBid, positions, espnValue from espnDomAuctionValues, maxBidRecommendation from budgetCurve)
     - strategy: from context.strategy

5. Create `useNarrator(engineSignals: DraftEngineSignals | null)` hook:
   - Read narrator store state via `useNarratorStore()`
   - Read draft store via `useDraftStore()` for: remainingBudget, myRoster, currentAuctionPlayer, strategy, leagueCategories, auctionValues, allPicks, espnDomAuctionValues
   - Refs: debounceTimerRef, abortControllerRef, lastDedupeKeyRef, prevArchetypeRef, prevPacingRef

   - `fireNarration` callback:
     - CRITICAL: Read `sessionCallCount` from `useNarratorStore.getState().sessionCallCount` (NOT from closure -- Pitfall #6 from research)
     - Check cap: if count >= SESSION_CAP, return early
     - Build dedupeKey, skip if identical to lastDedupeKeyRef
     - Cancel in-flight request via abortControllerRef
     - Set loading true, increment call count
     - Read backendUrl from chrome.storage.local (same pattern as api-client.ts)
     - Build NarratorPayload via buildNarratorPayload()
     - POST to `${baseUrl}/api/draft/narrate`
     - On success: setNarration(data.narration)
     - On error (not AbortError): console.warn only -- graceful degradation, no error shown to user
     - Finally: setLoading(false)

   - useEffect watching trigger conditions:
     - Guard: if no engineSignals or sessionCallCount >= SESSION_CAP, return
     - Check alert severity trigger: any alert with severity > 0.65
     - Check archetype change: archetypeLabel !== prevArchetypeRef.current (only when picksAnalyzed >= 3)
     - Check budget pressure change: pacingStatus !== prevPacingRef.current
     - If no trigger reason, return
     - Clear existing debounce timer, set new one with DEBOUNCE_MS delay
     - Cleanup: clear timer on unmount
     - Dependency array: use specific sub-fields (signals?.alerts, signals?.archetype, signals?.budgetCurve.pacingStatus) NOT the whole object

   - `requestAdvice` callback (for manual "Ask for advice" button):
     - Guard: if no engineSignals or at cap, return
     - Clear debounce timer
     - Call fireNarration immediately with triggerReason "user_request"

   - Return `{ requestAdvice }`
  </action>

    - `grep "AbortController" packages/extension/lib/use-narrator.ts` confirms request cancellation
  </verify>
  <done>useNarrator hook exists with 1500ms debounce, deduplication key, 120-call session cap using getState(), AbortController for in-flight cancellation, and requestAdvice() for manual trigger. Graceful degradation on backend failure.</done>
