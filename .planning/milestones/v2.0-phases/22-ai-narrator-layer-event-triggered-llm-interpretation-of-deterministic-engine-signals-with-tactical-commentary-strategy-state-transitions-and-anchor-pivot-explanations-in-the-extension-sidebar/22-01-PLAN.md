   - Export `DraftNarratorAgent` class following existing agent pattern:
     - Constructor accepts optional Pino `logger`
     - Constructor reads `process.env.OPENAI_API_KEY` and throws descriptive error if missing

   - `async narrate(payload: NarratorPayload): Promise<string>` method:
     - Calls `this.client.chat.completions.create()` with:
       - model: MODEL_ID constant
       - system message: tactical fantasy baseball auction draft advisor prompt (see SYSTEM_PROMPT in 22-RESEARCH.md)
       - user message: built from payload by `buildUserMessage()` private method
       - max_tokens: 200
       - temperature: 0.4
     - Returns trimmed text from `completion.choices[0]?.message?.content ?? ""`
     - Logs `triggerReason` at debug level
   - Private `buildUserMessage(payload)` method:
     - Serializes structured fields as labeled sections (DRAFT PHASE, TRIGGER, NOMINATED, ACTIVE ALERTS, INFLATION, BUDGET, ARCHETYPE, PUNTED, PIVOT OPTIONS, SCARCITY, CAT GAPS, STRATEGY)
     - Only includes sections with meaningful data (skip empty arrays, null archetype, etc.)
     - Alerts limited to top 3 by severity
     - Scarcity filtered to scarcityIndex > 0.65
     - Category gaps filtered to categoryRiskScore > 0.65

3. Add `OPENAI_API_KEY=` to `packages/backend/.env.example` with a comment:
