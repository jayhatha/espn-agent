  <action>
Create new Chrome extension package using WXT framework with TypeScript and React. Per RESEARCH.md, WXT is the 2026 market leader (43% smaller bundles than Plasmo, Vite-based with HMR).

**1. Initialize extension package:**
```bash
cd packages
pnpm create wxt extension
cd extension
pnpm add zustand webext-bridge react react-dom
pnpm add -D @types/chrome @types/react @types/react-dom tailwindcss postcss autoprefixer
```

**2. Configure WXT manifest (wxt.config.ts):**
- Manifest V3 configuration
- Permissions: ['storage', 'tabs']
- Host permissions: ['https://fantasy.espn.com/*']
- Content script matches: ['https://fantasy.espn.com/baseball/draft*']
- Web accessible resources: ['assets/*.json', 'assets/*.png']
- Name: "ESPN Draft Assistant"
- Description: "Real-time draft recommendations for ESPN fantasy baseball"

**3. Create background service worker (entrypoints/background.ts):**
- Message routing setup using webext-bridge
- Handler for GET_RANKINGS message type
- Handler for GET_AUCTION_VALUES message type
- Log initialization on install

**4. Create extension popup (entrypoints/popup.html + popup.tsx):**
- Basic React app with league selection UI
- Input field for backend API token (manual entry for v1)
- Save token to chrome.storage.local on submit
- Display saved token status (masked)
- Instructions: "Copy your auth token from the web app Settings page"

**5. Generate baseline rankings JSON:**
Fetch latest draft rankings from backend API (production or local dev) for a sample 12-team league, extract top 300 players, save to assets/baseline-rankings.json with this schema:
```json
[
  {
    "playerId": 12345,
    "playerName": "Aaron Judge",
    "positions": ["OF"],
    "primaryPosition": "OF",
    "vbdScore": 85.3,
    "tier": 1,
    "projectedStats": { "HR": 58, "RBI": 144, ... }
  }
]
```
If no backend available, use placeholder data with ~50 realistic players.

**6. Create API client (lib/api-client.ts):**
- Import baseline rankings JSON
- Export `getRankings(leagueId, options)` function that:
  - Attempts fetch to `${BACKEND_URL}/api/leagues/${leagueId}/draft/rankings`
  - Uses Authorization header with token from chrome.storage.local
  - 3-second timeout via AbortSignal
  - Falls back to bundled baseline rankings on error
- Export `getAuctionValues(leagueId, options)` function with same pattern for auction endpoint
- Log warnings when falling back to baseline data

**7. Update turbo.json:**
Add extension package to build pipeline with dependencies on shared package.

**Why this works:** WXT handles all Manifest V3 boilerplate (service workers, content script bundling, HMR). Bundling baseline rankings ensures extension always functions even offline. API client pattern enables hybrid data strategy (backend when available, bundled fallback otherwise).

**3. Create content script stylesheet (entrypoints/content.css):**
