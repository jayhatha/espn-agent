**Part A: Create `packages/extension/components/BuildArchetypePanel.tsx`**

Build a React component that visualizes the `BuildArchetypeSignal` from the archetype engine. Follow the existing design system used in `EngineInsights.tsx` (same bg-surface-secondary/surface-tertiary patterns, text-body-sm/xs classes, details/summary collapsible pattern).

The component receives `signal: BuildArchetypeSignal | null` as prop. Return null if signal is null or picksAnalyzed is 0.

Structure (per locked decisions from CONTEXT.md):
1. **Collapsed by default** — use `<details>` (no `open` attribute, unlike the existing sections which use `<details open>`)
2. **Summary bar**: "Build Analysis" label + archetype badge (if confidence >= 0.5) or "Building..." text (if < 0.5 but > 0 picks)
3. **Category ceiling bars** — one per category in `signal.ceilings`:
   - Left: stat_key label (10-char width)
   - Middle: horizontal bar with two layers:
     - Solid portion = currentTotal / competitiveTarget (what's already drafted)
     - Semi-transparent extension = (ceilingTotal - currentTotal) / competitiveTarget (greedy fill potential)
     - Vertical marker at 100% = competitive target line
   - Right: ceilingTotal / competitiveTarget numeric display
   - Punted indicator: if `isPunted`, show a subtle crossed-circle icon or muted text color on the stat_key. Use `text-content-secondary` and a small Unicode symbol (e.g., the "null set" symbol). Don't use red/bold — user may be intentionally punting.
   - For LOWER_BETTER stats (ERA, WHIP): invert the bar logic. Lower ceiling = better. Bar fills from right to left, or use a different visual cue. Keep it consistent: "more bar fill = closer to competitive" regardless of direction.
4. **Spending split** — small text showing "Hitting: $X / Pitching: $Y" committed spend
5. **Pivot players section** (only if pivotPlayers.length > 0):
   - Divider line
   - "Pivot Players" header (text-body-xs font-semibold)
   - Each pivot player: name on left, "$cost -> +lift category" on right
   - Use `text-body-xs` for compact display

Color classes to use (from existing design system):
- Good/on-track: `bg-positive/60`, `text-positive`
- Warning/needs attention: `bg-warning/60`, `text-warning`
- Punted/muted: `bg-surface-tertiary`, `text-content-secondary`
- Accent for archetype badge: `bg-accent/10 text-accent`

For rate stat display formatting:
- Counting stats: round to integer (e.g., "220/250")
- Rate stats (AVG, ERA, WHIP, OPS): show 3 decimal places (e.g., ".275/.260")
