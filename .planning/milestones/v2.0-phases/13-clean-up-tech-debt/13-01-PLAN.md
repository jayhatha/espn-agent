    ```typescript
      // Batting
      AB?: number;

      SB?: number;
      BB?: number;
      HBP?: number;

    }
    ```

    2. Update isCategoryRelevant method (line 988):
    - Add: `const components: StatComponents = JSON.parse(projection.stat_components_json);`
    - Replace: `projection.ab` with `components.AB`
    - Replace: `projection.ip` with `components.IP`

    3. Update getProjectedCategoryValue method (line 1008):
    - Add: `const components: StatComponents = JSON.parse(projection.stat_components_json);`
    - Replace all lowercase field access with uppercase component access:
      - AVG: `(components.H || 0) / Math.max(1, components.AB || 1)`
      - OBP: `((components.H || 0) + (components.BB || 0) + (components.HBP || 0)) / Math.max(1, (components.AB || 0) + (components.BB || 0) + (components.HBP || 0) + (components.SF || 0))`

      - OPS: OBP + SLG
      - ERA: `(9 * (components.ER || 0)) / Math.max(0.1, components.IP || 0.1)`
      - WHIP: `((components.H_P || 0) + (components.BB_P || 0)) / Math.max(0.1, components.IP || 0.1)`
      - Counting stats: `components.R || 0`, `components.HR || 0`, etc.

    This is a CRITICAL bug fix - trade recommendations currently produce incorrect results due to undefined field access.
