<objective>
Add interactive transaction annotations and date range filtering to the trends timeline.

Purpose: Users need to see HOW their roster moves (trades, waiver adds/drops) impacted standings over time. Currently the trends page shows standings lines but transactions are displayed as barely-visible text labels with no details. This plan makes annotations interactive with hover tooltips showing player names, adds date range filtering for sub-season analysis, and filters annotations by selected team to prevent clutter.

Output: Enriched annotations API endpoint, TransactionMarker component, DateRangeFilter component, and integrated trends page with interactive annotations and flexible date filtering.
</objective>

    6. Return `{ annotations: enrichedAnnotations }`.

    },
