<objective>
Create the Fastify WebSocket hub that acts as a relay between the Chrome extension and mobile phone clients during live auction drafts.

Purpose: The extension cannot run a WebSocket server (browser context limitation). The Fastify backend serves as the hub that both the extension background service worker and the mobile page connect to as WS clients. State snapshots flow extension -> hub -> mobile. Control commands flow mobile -> hub -> extension.

Output: A new `/draft/live` WebSocket route in the backend, with @fastify/websocket registered, CORS relaxed for LAN origins on WS routes, and role-based client management (extension vs mobile).
</objective>

<task type="auto">
  <name>Task 2: Create the WebSocket hub route at /draft/live</name>
  <files>packages/backend/src/api/draft-live.ts</files>
  <action>
Create `packages/backend/src/api/draft-live.ts` with the following:

1. Export an async function `draftLiveRoutes(app: FastifyInstance)` that registers a single WebSocket route.

2. Maintain state:
   - `extensionSocket: WebSocket | null` — the single extension client
   - `mobileClients: Set<WebSocket>` — all connected mobile clients
   - `latestSnapshot: string | null` — cache the last state snapshot so newly connecting mobile clients get immediate state

3. Route: `app.get("/draft/live", { websocket: true }, (socket, req) => { ... })`

4. Parse role from query params: `const params = new URLSearchParams(req.url.split("?")[1] ?? ""); const role = params.get("role");`

5. If role === "extension":
   - Set `extensionSocket = socket`
   - Log: `app.log.info("[DraftLive] Extension connected")`
   - On "message": parse JSON. If `msg.type === "PING"`, respond with `{ type: "PONG" }`. Otherwise, store `raw.toString()` as `latestSnapshot` and fan out to all mobile clients where `client.readyState === 1`.
   - On "close": set `extensionSocket = null`, log disconnect.
   - On "error": log and clean up.

6. If role !== "extension" (treat as mobile):
   - Add socket to `mobileClients`
   - Log with client count
   - On connect: if `latestSnapshot` exists, immediately send it to give the phone current state.
   - On "message": parse JSON. If `msg.type === "CONTROL"` and `extensionSocket?.readyState === 1`, forward `raw.toString()` to extensionSocket.
   - On "close": remove from `mobileClients`, log with remaining count.
   - On "error": log and clean up.

7. Type the message interfaces locally (no separate file needed):
   - `{ type: "PING" }` / `{ type: "PONG" }`
   - `{ type: "STATE_SNAPSHOT", payload: Record<string, unknown>, engineSignals?: Record<string, unknown>, ts: number }`
   - `{ type: "CONTROL", action: string, payload?: unknown }`

8. Wrap all JSON.parse calls in try/catch — log and ignore malformed messages.
  </action>
