# Phase 97-01 Plan: Snapshot Pipeline Integration Tests

## Goal

Write integration tests that cover the three critical seams in the snapshot pipeline.

## Tasks

### Task 1: empty-array guard

**Test:** `SnapshotRepository.getPlayerProjections(runId, [])` returns `[]` without calling `selectFrom`
**Rationale:** Kysely generates invalid SQL for `WHERE col IN ()` — the guard prevents runtime DB errors when a roster is empty.

### Task 2: is_degraded=true — projections missing

**Test:** Degraded flag logic returns `isDegraded=true` + `degraded_reasons: ["projections_missing"]` when no `projections_run` row exists.

### Task 3: is_degraded=true — projections stale

**Tests:**

- `projDate !== snapDate` → `is_degraded=true`, reason: `"projections_stale"`
- `staleness !== "fresh"` → `is_degraded=true`, reason: `"projections_stale"`
- Matching date + `staleness="fresh"` → `is_degraded=false`, empty reasons

### Task 4: Date object handling

**Test:** Projections run `as_of_date` as `Date` object (DB may return objects) matches snapshot date string correctly.

## Acceptance

- `npx vitest run src/__tests__/snapshot-pipeline.test.ts` passes 8/8 tests
- All tests follow existing mock pattern from `test-helpers.ts`
