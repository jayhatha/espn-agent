# Phase 96-01 Plan: Frontend Query Hook Layer

## Goal

Create a centralized hook layer in `packages/frontend/src/lib/hooks/` so pages consume named hooks instead of inline `useQuery()` calls.

## Tasks

### Task 1: Create hook files

**Files created:**

- `packages/frontend/src/lib/hooks/use-league.ts` — `useLeagueStatus`, `useLeagueTeams`
- `packages/frontend/src/lib/hooks/use-standings.ts` — `useProjectedStandings`
- `packages/frontend/src/lib/hooks/use-waivers.ts` — `useWaiverRecommendations`, `useFreeAgents`
- `packages/frontend/src/lib/hooks/use-trades.ts` — `useTradeRecommendations`
- `packages/frontend/src/lib/hooks/index.ts` — barrel re-exports

All hooks use `queryKeys` factories from `@/lib/query-keys`. Each includes explicit `staleTime`.

### Task 2: Update standings page

**File:** `packages/frontend/src/app/leagues/[id]/standings/page.tsx`

- Import `useProjectedStandings` from `@/lib/hooks`
- Replace inline `useQuery({ queryKey: ["standings", ...], queryFn: ... })` with `useProjectedStandings(leagueId)`

### Task 3: Update waivers page

**File:** `packages/frontend/src/app/leagues/[id]/waivers/page.tsx`

- Import `useWaiverRecommendations`, `useFreeAgents` from `@/lib/hooks`
- Replace AI recommendations `useQuery` with `useWaiverRecommendations`
- Replace free agents `useQuery` with `useFreeAgents`

## Acceptance

- All 7 frontend files pass `get_errors()` with 0 TypeScript errors
