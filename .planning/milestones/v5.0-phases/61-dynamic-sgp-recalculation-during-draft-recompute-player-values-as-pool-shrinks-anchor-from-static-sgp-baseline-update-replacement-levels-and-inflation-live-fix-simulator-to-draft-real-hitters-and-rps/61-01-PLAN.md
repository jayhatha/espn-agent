<objective>
Implement dynamic SGP recomputation inside the auction simulator so player values update as the pool shrinks.

Purpose: Static SGP computed once from the full 400-player pool becomes stale as players are drafted. By pick 200, the replacement level hasn't shifted — we're still valuing players against a pool that's half gone. Dynamic recomputation corrects this by recomputing denominators from the actual remaining pool.

Output: Modified `tools/simulate-auction.ts` with per-5-pick SGP recomputation. All existing simulation stats remain valid (no regression). SGP dollar values for late-round players now reflect the true remaining talent pool.
</objective>

<feature>
  <name>Dynamic SGP Recalculation in Simulator</name>
  <files>tools/simulate-auction.ts</files>
  <behavior>
    The `simulateAuction()` function currently calls `computeSGP(players)` once before the while loop and uses those static values throughout all 400+ picks. The fix recomputes SGP from the remaining available pool every 5 picks.

    Expected behavior cases:
    - At pick 0: dynamic SGP === static SGP (full pool available, same inputs)
    - At pick 5: dynamic SGP recomputes from pool minus 5 drafted players — values shift slightly
    - At pick 200: dynamic SGP reflects only the remaining 200 players — replacement level is now the 200th-best remaining player, not the original 400th
    - totalPositiveSGP updates in sync with dynamicSGPValues — same recompute interval
    - For top-60 PL-ranked SPs: dynamic SGP feeds computeOurBid() → sgpDollars → then the SP tier cap logic in computeOurBid() applies its floor/ceiling (tier cap is NOT bypassed)
    - overpricingScores used for nomination are also refreshed at the same interval (recompute when dynamicSGPValues updates)
  </behavior>
  <implementation>

    ### GREEN Phase

    Implement the dynamic SGP recomputation:

    1. Before the `while (available.size > 0)` loop, keep the existing `computeSGP(players)` call but rename:
       ```typescript
       const staticSGPValues = computeSGP(players); // full pool — initial anchor
       let dynamicSGPValues = [...staticSGPValues];  // starts identical
       let dynamicTotalPositiveSGP = staticSGPValues.reduce((s, v) => s + Math.max(0, v), 0);
       let lastRecomputeAvailSize = available.size;
       let sgpRecomputeCount = 0;
       const RECOMPUTE_EVERY = 5;
       ```

    2. Remove the existing `const totalPositiveSGP = sgpValues.reduce(...)` line (it's now `dynamicTotalPositiveSGP`).

    3. At the top of the while loop (before nomination logic), add the recompute check:
       ```typescript
       if (lastRecomputeAvailSize - available.size >= RECOMPUTE_EVERY) {
         const availArr = Array.from(available);
         const availPlayers = availArr.map(i => players[i]);
         const freshSGP = computeSGP(availPlayers);
         // Reset to zeros — only available players get values
         dynamicSGPValues = new Array(players.length).fill(0);
         for (let j = 0; j < availArr.length; j++) {
           dynamicSGPValues[availArr[j]] = freshSGP[j];
         }
         dynamicTotalPositiveSGP = freshSGP.reduce((s, v) => s + Math.max(0, v), 0);
         lastRecomputeAvailSize = available.size;
         sgpRecomputeCount++;
       }
       ```

    4. Replace all references to `sgpValues[nomIdx]` and `sgpValues[i]` inside the while loop with `dynamicSGPValues[...]`. Specifically:
       - Line ~773: `const playerSGP = Math.max(0, sgpValues[nomIdx])` → `dynamicSGPValues[nomIdx]`
       - Line ~774: `const sgpDollars = totalPositiveSGP > 0 ? (playerSGP / totalPositiveSGP) * ...` → use `dynamicTotalPositiveSGP`
       - Line ~782: `const totalRemainingValue = Array.from(available).reduce(...)` — if this uses `sgpValues`, update to `dynamicSGPValues`
       - Line ~858: `const blendedVal = sgpDollars > asv && asv > 0 ? ...` — this uses `sgpDollars` which is already updated

    5. Recompute `overpricingScores` at the same interval as SGP (inside the recompute block):
       ```typescript
       // Rebuild overpricing scores from fresh SGP + fresh available pool
       for (const idx of available) {
         const p = players[idx];
         const asv = asvMap.get(p.normalizedName) ?? p.dollars;
         const sgpD = dynamicTotalPositiveSGP > 0
           ? (Math.max(0, dynamicSGPValues[idx]) / dynamicTotalPositiveSGP) * totalLeagueBudget
           : p.dollars;
         overpricingScores[idx] = asv - sgpD;
       }
       ```

    6. Return `sgpRecomputeCount` in the `simulateAuction()` result object (add to the return type).

    7. In the post-simulation output, log: `console.log(\`Dynamic SGP recomputes: ~${mean(results.map(r => r.sgpRecomputeCount)).toFixed(0)} per sim\`);`

    8. Keep `sgpValues` variable (the original static array) available for any code that still needs it outside the while loop (e.g., the pre-loop `overpricingScores` initialization, the post-loop stats calculation). These outside-loop references are fine to keep on static values.
