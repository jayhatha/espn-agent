**SignalStrip.tsx** — A compact horizontal badge row displaying 4 signals. Props:

```typescript
interface SignalStripProps {
  endgameMode: boolean;
  inflationBand: "overspending" | "neutral" | "buying_window" | "strong_value";
  hitterSpent: number;
  pitcherSpent: number;
  spCount: number;        // Number of SP on myRoster
  totalSpSlots: number;   // Total SP slots (from detectedRosterSlots or default 5)
}
```

Layout: Single row `flex flex-wrap gap-1.5 px-3 py-2 bg-grafana-panel border-b border-grafana-border`.

Badges (each is a small pill `text-[10px] font-semibold px-2 py-0.5 rounded`):
1. **Endgame badge** (ALWAYS visible per locked decision):
   - `endgameMode=false` → green background (`bg-grafana-endgame-normal text-white`) label "NORMAL"
   - `endgameMode=true` → red background (`bg-grafana-endgame-active text-white`) label "ENDGAME"
2. **Inflation band badge**: Map `inflationBand` to display using this lookup:
   - `overspending` → `bg-grafana-inflation-overspending text-white` label "OVERSPEND"
   - `neutral` → `bg-grafana-inflation-neutral text-white` label "NEUTRAL"
   - `buying_window` → `bg-grafana-inflation-buying text-white` label "BUY WINDOW"
   - `strong_value` → `bg-grafana-inflation-strong text-white` label "STRONG VALUE"
3. **Budget split badge**: Compute `actualHitPct = totalSpent > 0 ? Math.round(hitterSpent / (hitterSpent + pitcherSpent) * 100) : 75`. Display: `HIT {actualHitPct}%` with `bg-grafana-panel border border-grafana-border text-grafana-text`.
4. **SP tier badge**: Display `SP {spCount}/{totalSpSlots}` with `bg-grafana-panel border border-grafana-border text-grafana-text`.

**CategoryHeatmap.tsx** — Horizontal bar heatmap for projected category standings. Props:

```typescript
interface CategoryHeatmapProps {
  projectedStandings: ProjectedStandingsSignal | null;
  myTeamId: string | null;
  leagueCategories: Category[];
}
```

Internal state: `useState<'rank' | 'stat'>('rank')` for click-toggle.

**Data extraction:** Find user's team in `projectedStandings.standings` by matching `myTeamId`. Read `categoryRanks` and `categoryValues` from that team's `ProjectedTeamStanding`. The categories to display come from `leagueCategories` (use `statKey` field). Also compute overall rank from `projectedStandings.myTeamRank`.

**Layout:** `px-3 py-2 bg-grafana-panel border-b border-grafana-border` — NOT collapsible (locked decision: always visible).

Section header: `text-[10px] text-grafana-muted uppercase tracking-wide mb-1.5` with "Category Ranks" (or "Category Stats" when toggled). Make the header clickable to toggle view.

For each category in `leagueCategories`:
- Display category label (statKey like HR, RBI, etc.) in `text-[10px] text-grafana-muted w-8`
- Horizontal bar: width proportional to rank (rank 1 = full width, rank N = 1/N width). Use `(totalTeams - rank + 1) / totalTeams * 100` for percentage.
- Bar color via rank-to-color function:
  ```
  pct = (rank - 1) / max(1, totalTeams - 1)
  pct <= 0.25 → '#37872d' (green)
  pct <= 0.50 → '#e0b400' (yellow)
  pct <= 0.75 → '#f2495c' (orange-red)
  else → '#c4162a' (red)
  ```
- Right side label: In 'rank' mode show rank number (e.g., "3rd"). In 'stat' mode show the stat total value (use `categoryValues[statKey]`). For rate stats (ERA, WHIP, OPS, AVG, OBP, SLG), format to 2-3 decimal places. For counting stats, round to integer.

Final row: "Overall" with `projectedStandings.myTeamRank` as the rank and total roto points as the value.

**Empty state:** When `projectedStandings` is null, show placeholder text "Waiting for draft data..." in `text-grafana-muted text-body-xs` with skeleton gray bars.

**PositionSupplyHeatmap.tsx** — Position supply grid. Props:

```typescript
interface PositionSupplyHeatmapProps {
  rankings: DraftRanking[];
  allPicks: DraftPick[];
}
```

Pool sizes (from locked decision):
```
SUPPLY_POOL_SIZES = { C: 15, '1B': 15, '2B': 15, '3B': 15, SS: 15, OF: 50, SP: 30, RP: 15 }
```

**Computation (inline useMemo):**
1. Build `draftedIds = new Set(allPicks.map(p => p.playerId))`
2. For each position in SUPPLY_POOL_SIZES:
   - Filter rankings where `r.positions.some(p => p.toUpperCase().includes(pos))` (matching existing pattern)
   - Sort by `externalRank` ascending (lower = better)
   - Take top N (pool size)
   - Count how many are in `draftedIds`
   - Result: `{ drafted: number, total: number }`

**Layout:** `px-3 py-2 bg-grafana-panel border-b border-grafana-border`.

Section header: `text-[10px] text-grafana-muted uppercase tracking-wide mb-1.5` "Position Supply".

Display as a compact grid (2 columns or flex-wrap). Each position shows:
- Position label in `text-[10px] font-semibold text-grafana-text`
- Small horizontal bar (`h-1.5 rounded-full`) showing drafted/total ratio
- Bar fill color: < 50% drafted = `bg-grafana-positive`, 50-75% = `bg-grafana-warning`, > 75% = `bg-grafana-negative`
- Text label: `{drafted}/{total}` in `text-[10px] text-grafana-muted`

When `rankings.length === 0`: Show "Load rankings to see position supply" in muted text.
