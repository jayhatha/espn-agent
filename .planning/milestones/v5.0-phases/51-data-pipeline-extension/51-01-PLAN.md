# Phase 51 Plan 01: Data Pipeline for Extension

## Objective
Add CSV paste/upload capability to the extension popup so users can load FanGraphs projections and ESPN auction values directly without needing the backend running.

## Context
- @packages/extension/entrypoints/popup/index.tsx — existing popup with Settings and Rankings tabs
- @packages/extension/lib/draft-state.ts — Zustand store with rankings, auctionValues, espnDomAuctionValues
- @packages/extension/lib/api-client.ts — current buildBundledRankings() for reference
- @packages/extension/lib/engine/types.ts — PoolPlayer type
- @packages/extension/lib/engine/sgp.ts — SGP computation reference

## Tasks

### Task 1: CSV parser utility
type="auto"

Create `packages/extension/lib/csv-parser.ts` with:
- `parseFanGraphsBatterCSV(csvText: string)` — parse FanGraphs hitter projections CSV
- `parseFanGraphsPitcherCSV(csvText: string)` — parse FanGraphs pitcher projections CSV
- `parseESPNAuctionCSV(csvText: string)` — parse ESPN auction values (simple name + dollar value)
- Map parsed data to PlayerRanking[] and AuctionValue[] formats compatible with the store
- Handle header detection, empty rows, quoted fields

**Done:** File exists, exports parse functions that return typed results.

### Task 2: Data tab in popup
type="auto"

Add a "Data" tab to the popup alongside Settings and Rankings:
- Textarea for pasting FanGraphs hitter CSV + "Load Hitters" button
- Textarea for pasting FanGraphs pitcher CSV + "Load Pitchers" button
- Textarea for pasting ESPN auction values CSV + "Load Values" button
- Status messages showing loaded counts
- Stores parsed data into Zustand rankings/auctionValues

**Done:** Data tab renders, buttons trigger parse + store, status shows counts.

### Task 3: Build verification
type="auto"

Run `pnpm --filter extension build` and fix any type/build errors.

**Done:** Build succeeds cleanly.

## Verification
- [ ] `pnpm --filter extension build` succeeds
- [ ] CSV parser handles FanGraphs CSV format correctly
- [ ] Popup has 3 tabs: Settings, Rankings, Data
- [ ] Pasting CSV and clicking Load stores data in Zustand

## Success Criteria
Users can paste FanGraphs CSV data directly into the extension popup to load projections without the backend.
