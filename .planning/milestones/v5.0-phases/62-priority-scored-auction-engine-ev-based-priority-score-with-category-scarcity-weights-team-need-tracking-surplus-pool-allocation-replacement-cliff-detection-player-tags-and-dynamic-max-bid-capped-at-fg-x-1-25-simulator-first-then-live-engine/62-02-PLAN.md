## Objective

Create `category-state.ts` — computes `CategoryState` once per pick from the current draft state. Implements scarcity weight computation, pace tracking with LOWER_BETTER inversion, surplus pool accumulation from bargain wins, and replacement cliff detection. This module is called in `computeDraftEngine` before the bid worker is dispatched.

## Locked Decisions (do NOT deviate)

1. scarcity_weight = 1 + (1 - remaining_supply_ratio) where remaining_supply_ratio = pool_remaining_stat_total / initial_pool_stat_total. Clamped [1.0, 2.0].
2. team_need_weight inputs: paceRatios (pace < 0.85 → increase category weight; pace > 1.05 → decrease). Pace < 0.80 mid-draft → set forceAcquisition flag in CategoryState.
3. Surplus = max(0, FG$ - actualPaid) per bargain win. Tracked as running total in CategoryState.
4. Cliff: dropoff = player_value - next_best_value on undrafted pool sorted by FG$. If dropoff > $5, player is in cliffPlayers.
5. LOWER_BETTER categories (ERA, WHIP): pace = target / current_total (inverted). When no current total → pace = 1.0.
6. Initial pool stats cached at module level, keyed by leagueId. Invalidated when leagueId changes.
7. CategoryState uses plain objects and string[] (not Maps/Sets) — must be structured-clone-safe.

Create `packages/extension/lib/engine/category-state.ts`. Pure function module, no side effects except module-level cache (same pattern as cachedSGPVectors in index.ts).

**Module-level cache (two variables):**
```typescript
let cachedLeagueId: string | number | null | undefined = undefined;
let cachedInitialPoolStats: Record<string, number> = {};
```

**Export interface (for index.ts wiring):**
```typescript
export interface ComputeCategoryStateInput {
  leagueId: number | null | undefined;
  undraftedPlayers: PoolPlayer[];           // current undrafted pool
  allUndraftedPlusDrafted: PoolPlayer[];    // all FG players (used for initial stats on first call)
  myDraftedPlayers: Array<{ fgDollars: number; paidDollars: number; normalizedName: string }>;
  myTotals: Record<string, number>;         // from teamDraftedTotals.get(myTeamId) ?? {}
  categoryTargets: Record<string, number>;  // from input.categoryTargets ?? {}
  categoryDirections: Record<string, "HIGHER_BETTER" | "LOWER_BETTER">;
  totalPicksMade: number;
  totalPicksInDraft: number;               // totalTeams × rosterSize
}
```

**Export `computeCategoryState(input: ComputeCategoryStateInput): CategoryState`:**

1. **Initial pool stats (cache):**
   - If leagueId !== cachedLeagueId: recompute from `allUndraftedPlusDrafted` (all FG players, not just undrafted)
   - For HIGHER_BETTER stats: initialPoolStats[stat] = sum of player.stats[stat] across all players
   - For LOWER_BETTER stats (ERA, WHIP): initialPoolStats[stat] = pool-median value (not sum) — use median of players with IP > 0
   - Cache and return cachedInitialPoolStats

2. **Scarcity weights:**
   - For each HIGHER_BETTER stat: remainingTotal = sum of player.stats[stat] across undraftedPlayers; ratio = remainingTotal / max(1, initialPoolStats[stat]); weight = clamp(1 + (1 - ratio), 1.0, 2.0)
   - For LOWER_BETTER stat (ERA, WHIP): use pool median of undrafted players with IP > 0; remainingMedian = median(IP > 0 pitchers stats[stat]); ratio = remainingMedian / max(0.01, initialPoolStats[stat]); weight = clamp(1 + (1 - ratio), 1.0, 2.0) — same formula, just median instead of sum
   - Default weight 1.0 for stats not found

3. **Pace ratios:**
   - For HIGHER_BETTER: paceRatio = myTotals[stat] / max(1, categoryTargets[stat]). When target missing → paceRatio = 1.0.
   - For LOWER_BETTER (ERA, WHIP): when myTotals[stat] > 0 AND categoryTargets[stat] > 0: paceRatio = categoryTargets[stat] / myTotals[stat]; else paceRatio = 1.0
   - Force acquisition: if paceRatio < 0.80 AND totalPicksMade > totalPicksInDraft × 0.20 → add to forceAcquisitionCategories (new field on CategoryState)

4. **Surplus pool:**
   - surplusPool = sum of max(0, p.fgDollars - p.paidDollars) across myDraftedPlayers
   - Only count when fgDollars > 0

5. **Cliff detection:**
   - For each contributing stat key (SB, SV, HR, K), find undraftedPlayers with player.stats[stat] > 0, sorted by FG$ descending
   - For the top player at each stat: dropoff = player.dollars - (second.dollars ?? 0)
   - If dropoff > 5: add player.normalizedName to cliffSet
   - Return as cliffPlayers: string[]

6. **Return `CategoryState`:**
```typescript
{
  scarcityWeights,          // Record<string, number>
  paceRatios,               // Record<string, number>
  surplusPool,              // number
  cliffPlayers,             // string[]
  initialPoolStats: cachedInitialPoolStats,
  categoryDirections,
  forceAcquisitionCategories: string[]  // stats below 80% pace mid-draft
}
```

Add `forceAcquisitionCategories: string[]` to the `CategoryState` interface in types.ts (add to plan 01's types.ts changes — executor should add this field when writing types.ts in plan 01, or add it here if plan 01 already ran).
