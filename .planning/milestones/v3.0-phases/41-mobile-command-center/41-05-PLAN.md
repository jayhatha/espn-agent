   - If `state.espnNominationQueue?.length > 0`:
     - Numbered list showing each queued player: position number, player name, position
     - Compact rows (py-2, text-sm)
     - No reorder UI for now (per research open question 2 — deferred due to fragile DOM simulation). Show read-only list.
   - If empty: "No players in nomination queue. Use the ESPN draft page to add players to your queue."

5. **Hitter/Pitcher Split** (moved from LiveTab for grouping with controls — OR keep in LiveTab, user preference):
   - Keep the slider in LiveTab since it's more of a strategy setting. QueueTab focuses on actions.
