## What Was Built

**Backend (Task 1):**
The `/api/leagues/:leagueId/free-agents` endpoint was rewritten to call `espnAdapter.fetchFreeAgents()` instead of reading from the stale `league_raw_payload` table. The key changes:

- Added `position?: string` querystring param — comma-separated position codes (e.g. `SP,RP`) passed to `fetchFreeAgents` as the `positions` array, which maps them to ESPN slot IDs via `ESPN_POSITION_TO_SLOT` and uses the `filterSlotIds` x-fantasy-filter
- Fetches league credentials (`espn_swid`, `espn_s2`) from DB to authenticate the live ESPN call
- Returns `pctOwned` and `pctStarted` directly from ESPN `player.ownership.percentOwned` / `percentStarted`
- Projection enrichment uses `player.id` (which IS the ESPN player ID after migration 016) to match `player_projection` rows

**Frontend (Task 2):**
Three changes to `waivers/page.tsx`:
- Added `pctStarted: number` to the `FreeAgent` interface
- Added `pctStarted: p.pctStarted ?? 0` to the `faRows` useMemo
- Added `% Start` SortHeader column and corresponding `pctStarted.toFixed(1)%` data cell after the existing `% Own` column

## Deviations from Plan

**1. [Rule 1 - Bug] Auth pattern corrected**
- **Found during:** Task 1
- **Issue:** Plan referenced `espn_swid_encrypted`/`espn_s2_encrypted`/`getEspnAuthFromEnv`/`decryptToken` — these don't exist in this codebase. Credentials are stored as plaintext `espn_swid`/`espn_s2` columns per migration 003.
- **Fix:** Used actual schema columns directly (same pattern as `leagues.ts` and `projections.ts`)
- **Files modified:** packages/backend/src/api/recommendations.ts

**2. [Rule 1 - Bug] Projection lookup corrected**
- **Found during:** Task 1
- **Issue:** Plan's initial query using `player.espn_player_id` fails because migration 016 dropped that column — `player.id` IS the ESPN player ID now. Joining through the `player` table was unnecessary.
- **Fix:** Query `player_projection` directly using `pp.player_id` filtered on ESPN IDs — no join needed
- **Files modified:** packages/backend/src/api/recommendations.ts

## Known Stubs

None. Both `pctOwned` and `pctStarted` are live data from ESPN's `player.ownership` object.
