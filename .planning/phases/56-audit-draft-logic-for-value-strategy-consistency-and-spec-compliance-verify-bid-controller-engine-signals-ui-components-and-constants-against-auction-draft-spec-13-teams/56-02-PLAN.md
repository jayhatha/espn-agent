**Research context:** `nomination-strategy.ts` computes nomination scores using a weighted formula: `normalizedOverpricing * 0.6 + opponentNeedFactor * 0.2 + myNonNeedFactor * 0.2`. The `auto-bid-controller.ts` `evaluateAndNominate` function (around line 689) computes its own raw score: `espnPrice - modelValue`. Both prioritize overpriced players but use different formulas.

**Steps:**

1. Read `auto-bid-controller.ts` to find the `evaluateAndNominate` function (or equivalent nomination logic). Identify exactly where it computes `nominationScore: espnPrice - modelValue`.

2. Read `nomination-strategy.ts` to understand the `recommendNomination` export signature — what parameters it takes and what it returns.

3. In `auto-bid-controller.ts`, replace the inline nomination scoring with a call to the engine's nomination strategy:
   - Import `recommendNomination` (or its scoring function) from `nomination-strategy.ts`
   - Replace the inline `espnPrice - modelValue` scoring with a call to the engine's scoring function
   - If `recommendNomination` requires parameters the controller doesn't have (like opponent need data), check if the controller has access to draft state / engine signals. If opponent need data is unavailable, pass neutral values (0.5) for the secondary factors — the overpricing factor (60% weight) will still dominate

4. If `nomination-strategy.ts` doesn't export a standalone scoring function (only the full `recommendNomination` that returns a player pick), extract the scoring logic into a separate exported `computeNominationScore(player, params)` function that both `recommendNomination` and the controller can call.

5. Ensure the auto-bid controller still:
   - Sorts nomination candidates by score (highest first)
   - Filters out already-drafted and nominated players
   - Respects the queue if one exists

**Important:** The auto-bid controller may need the scoring function in a simpler form than the full recommendation engine. If extracting a shared scoring function creates too much coupling, an acceptable alternative is to have the controller call the engine's `recommendNomination` directly and use its top pick, rather than re-scoring players inline.
