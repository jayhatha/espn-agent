## Locked Decisions (do NOT deviate)

1. priority_score = EV × category_weight × scarcity_weight × team_need_weight. EV = FG_Dollars - ESPN_ASV.
2. max bid = inflated FG$ + EV buffer + category bonus, hard capped at FG$ × 1.25 (1.25× raw FG$, not inflated).
3. Category weights: SB=1.5, SV=1.4, ERA=1.3, WHIP=1.3, OPS=1.2, HR=1.0, RBI=1.0, R=1.0, W=1.0, K=1.0.
4. scarcity_weight ∈ [1.0, 2.0], team_need_weight ∈ [1.0, 2.0].
5. Tags: is_SB_anchor (SB≥20), is_OPS_anchor (OPS≥.850), is_SP_anchor (K rate AND ERA AND WHIP all better than pool median), is_closer (SV>20), is_replaceable_bat (SB<5 AND OPS<.800).
6. Negative EV → priority_score = 0 at that component; max bid floors at 1.

Implement three exported functions:

**`getCategoryWeight(statKeys: string[]): number`** (internal helper, exported for tests):
- Returns max category weight among provided stat keys
- Weights: SB=1.5, SV=1.4, ERA=1.3, WHIP=1.3, OPS=1.2, HR=1.0, RBI=1.0, R=1.0, W=1.0, K=1.0
- Default weight 1.0 for unknown stats
- A player contributing to multiple categories gets the MAX weight (not sum)

**`computePriorityScore(player: PoolPlayer, fgDollars: number, espnAsv: number | null | undefined, categoryState: CategoryState): PriorityScoreResult`**:
1. EV = fgDollars - (espnAsv ?? fgDollars) — when ASV missing, EV=0 (treat as fairly priced)
2. Determine which stat keys the player contributes to: for hitters check SB,OPS,HR,RBI,R; for pitchers check SV,ERA,WHIP,K,W
3. Filter to stats where player.stats[key] > 0 (only meaningful contributions)
4. category_weight = getCategoryWeight(contributingStatKeys)
5. Look up scarcity_weight from categoryState.scarcityWeights using the primary contributing stat (highest weight); clamp [1.0, 2.0]
6. team_need_weight: compute from categoryState.paceRatios: for HIGHER_BETTER, need = max(0, (1 - paceRatio)); for LOWER_BETTER, need = max(0, (paceRatio - 1)). team_need_weight = 1 + min(1.0, max contributing need). Clamp [1.0, 2.0].
7. priority_score = max(0, EV) × category_weight × scarcity_weight × team_need_weight
8. evBuffer = EV > 0 ? Math.round(EV × 0.3) : 0  (30% of positive EV becomes bid buffer)
9. categoryBonus = Math.round((category_weight - 1.0) × scarcity_weight × 3) (max ~$5 for SB at peak scarcity)
10. cliffBonus = categoryState.cliffPlayers.includes(player.normalizedName) ? 3 : 0
11. surplusBonus = in top 3 priority targets? categoryState.surplusPool × 0.4, capped at fgDollars × 0.25 remaining headroom under cap; else 0
12. Return: { priorityScore, evBuffer, categoryBonus, playerTags: tagPlayer(player, poolMedians?), maxBid: 0 } — maxBid computed by computeEVMaxBid separately

For `tagPlayer` and `computeEVMaxBid`, see below. PriorityScoreResult.maxBid = computeEVMaxBid result.

**`computeEVMaxBid(fgDollars: number, evBuffer: number, categoryBonus: number, inflationFactor: number, budget: number, isEndgame: boolean): number`**:
1. base = fgDollars × inflationFactor
2. If isEndgame (budget ≤ $20): dampen evBuffer and categoryBonus by 0.7× each
3. raw = base + evBuffer + categoryBonus
4. cap = fgDollars × 1.25  (cap on RAW fgDollars, not inflated)
5. maxBid = Math.max(1, Math.round(Math.min(raw, cap, Math.max(1, budget - 1))))
6. Return maxBid

**`tagPlayer(player: PoolPlayer, poolMedians?: { kPerIP: number; era: number; whip: number }): string[]`**:
- is_SB_anchor: !isPitcher AND SB >= 20
- is_OPS_anchor: !isPitcher AND OPS >= 0.850
- is_closer: isPitcher AND SV > 20
- is_replaceable_bat: !isPitcher AND SB < 5 AND OPS < 0.800
- is_SP_anchor: isPitcher AND poolMedians provided AND (IP > 0) AND (K/IP > poolMedians.kPerIP) AND (ERA < poolMedians.era) AND (WHIP < poolMedians.whip)
- Returns string[] of all matching tags (empty if none)
