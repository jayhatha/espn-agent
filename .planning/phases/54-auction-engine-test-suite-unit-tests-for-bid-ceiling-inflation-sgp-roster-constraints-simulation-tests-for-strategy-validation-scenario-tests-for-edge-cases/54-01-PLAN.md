Create `inflation.test.ts` testing `computeInflation` from `../engine/inflation`:

1. **Basic computation**: 10 teams, $260 each budget, no picks yet, auction values summing to $2600. inflationFactor should be ~1.0 (neutral). Verify `inflationBand === "neutral"`.

2. **Overspending band** (inflationFactor < 1.00): Create scenario where totalRemainingBudget < normalizedRemainingValue. Example: 5 picks at $60 each ($300 spent), remaining budget $2300, remaining value pool worth $2500 normalized. Verify `inflationBand === "overspending"` and `percentOverMarket < 0`.

3. **Buying window band** (1.05 < factor <= 1.15): Scenario where league has overspent slightly — remaining budget exceeds normalized remaining value by 5-15%. Verify `inflationBand === "buying_window"`.

4. **Strong value band** (factor > 1.15): Heavy overspending scenario. Verify `inflationBand === "strong_value"`.

5. **Clamping**: Create extreme scenario where raw factor would be > 2.0 (tiny remaining value, large remaining budget). Verify `inflationFactor === 2.0` and `rawInflationFactor > 2.0`.

6. **Clamping lower bound**: Scenario where raw factor < 0.5. Verify `inflationFactor === 0.5`.

7. **Confidence**: Pool with >= 20 valued players remaining should be "high". Pool with < 20 valued players should be "low".

8. **Normalization**: Test with auction values that sum to more than league budget (e.g., FG values sum to $3500 for a $2600 league). Verify normalization factor adjusts correctly so inflation isn't always negative.

9. **allTeamBudgets fallback**: When `allTeamBudgets` is empty, inflation should estimate from picks. When populated, should use sum directly.

10. **Edge case**: No auction values (empty array) should return factor 1.0.

Use mock `DraftPick[]` and `AuctionValue[]` — these are simple objects with `playerId`, `cost`, `dollarValue` fields. Reference `@espn-fantasy/shared` types.

Create `budget-curve.test.ts` testing `computeBudgetCurve` from `../engine/budget-curve`:

1. **Endgame mode activation**: `remainingBudget=20` -> `endgameMode=true`. `remainingBudget=21` -> `endgameMode=false`.

2. **Pacing status**:
   - "ahead": budgetPressure > 1.05 (more budget remaining than optimal)
   - "on-track": budgetPressure between 0.95-1.05
   - "behind": budgetPressure < 0.95 (spent too much too fast)

3. **Min reserve**: With 10 remaining spots, reserve = 9. Usable budget = remainingBudget - 9.

4. **Max bid recommendation**: Should not exceed 35% of usable budget, should not exceed 110% of inflation-adjusted value, should be >= 1.

5. **Budget targets**: Always returns hitterBudgetTarget {min:185, max:205}, pitcherBudgetTarget {min:55, max:70}, benchBudget=5.

6. **Edge case**: 0 remaining roster spots -> averageRemainingPerPlayer = 0.

7. **Inflation-adjusted bid**: With inflationFactor=1.5 and playerValue=10, inflationAdjustedBid should be ~15 (capped by usableBudget).
