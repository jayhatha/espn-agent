Redesign the ActionItemsList component to use the editorial divider-list pattern from the research doc. The current card-per-item pattern with `border-l-4` colored borders and `rounded-lg p-4 border` must be replaced entirely.

**New structure for each action item:**
```tsx
<div className="divide-y divide-neutral-200">
  {displayItems.map((item) => (
    <div key={item.id} className="py-5 flex items-start gap-6">
      {/* Impact number: oversized, left-aligned, fixed width */}
      <div className="w-24 text-right flex-shrink-0 pt-1">
        <span className={cn("text-h2 font-display leading-none", getImpactClasses(item.impact))}>
          {item.impact}
        </span>
      </div>

      {/* Content: badge + title + description */}
      <div className="flex-1 min-w-0">
        <div className="flex items-center gap-2 mb-1">
          <Badge variant={getTypeBadgeVariant(item.type)} className="uppercase tracking-wide">
            {item.type}
          </Badge>
          <span className="text-caption uppercase tracking-wide text-content-tertiary">
            {item.priority} priority
          </span>
        </div>
        <p className="text-body font-semibold text-content mb-0.5">{item.title}</p>
        <p className="text-body-sm text-content-secondary">{item.description}</p>
      </div>

      {/* CTAs: stacked vertically on right */}
      <div className="flex flex-col gap-2 flex-shrink-0">
        {item.internalLink && (
          <Link href={item.internalLink}>
            <Button variant="secondary" size="sm">Analyze</Button>
          </Link>
        )}
        {item.espnLink && (
          <a href={item.espnLink} target="_blank" rel="noopener noreferrer">
            <Button size="sm">
              ESPN
              <ExternalLinkIcon className="ml-1.5 h-3.5 w-3.5" />
            </Button>
          </a>
        )}
      </div>
    </div>
  ))}
</div>
```

**Key changes from current:**
1. Remove `getPriorityClasses` function entirely (no more `border-l-4`, no more `bg-negative-light`/`bg-warning-light`/`bg-positive-light` per-item backgrounds). Priority is shown as a text label, not a colored bar.
2. Impact number moves from a small inline `text-body-sm` to `text-h2 font-display` — it becomes the visual anchor of each row. Keep the existing `getImpactClasses` for positive (text-positive) / negative (text-negative) coloring.
3. Replace the individual card hover (`hover:shadow-card-hover`) with the divider-list pattern (`divide-y divide-neutral-200`). Items are separated by thin lines, not card borders.
4. Buttons use the design system `<Button>` component with `variant="secondary"` for Analyze and default for ESPN (already have these components).
5. Remove the outer `space-y-3` wrapper and replace with `divide-y`.

**Empty state** — also update to remove the card border:
```tsx
if (items.length === 0) {
  return (
    <div className="py-12 text-center">
      <ClockIcon className="w-10 h-10 text-content-tertiary mx-auto mb-3" />
      <p className="text-body font-medium text-content-secondary mb-1">No Recommended Actions</p>
      <p className="text-body-sm text-content-tertiary">Your team is performing well!</p>
    </div>
  );
}
```
Remove the bordered box (`border border-neutral-200 rounded-card p-8`) from the empty state.

**Responsive:** On small screens, the layout should stack: impact above content. Use `flex-col sm:flex-row` for the item row:
```tsx
<div className="py-5 flex flex-col sm:flex-row sm:items-start gap-4 sm:gap-6">
```
On mobile, the impact number is left-aligned (remove `text-right` on small, add `sm:text-right`):
```tsx
<div className="sm:w-24 sm:text-right flex-shrink-0">
```

**Preserve** the `remainingCount` indicator at the bottom.

Import `Button` from `@/components/ui/Button` (replace the inline button styles for Analyze/ESPN links).
