**1. layout.tsx — Add DM Serif Display font:**
Import `DM_Serif_Display` from `next/font/google` alongside existing Inter import. Configure it:
```tsx
const dmSerifDisplay = DM_Serif_Display({
  weight: '400',
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-display',
});
```
Note: DM Serif Display only has weight 400 — bold appearance comes from the serif design itself, not font-weight. Add the variable to the `<html>` className alongside the existing `inter.variable`:
```tsx
<html lang="en" className={`${inter.variable} ${dmSerifDisplay.variable}`}>
```

**2. tailwind.config.js — Add font-display family:**
In `theme.extend`, add a `fontFamily` key:
```js
fontFamily: {
  display: ['var(--font-display)', 'Georgia', 'serif'],
},
```
This enables `font-display` as a Tailwind utility class.

**3. globals.css — No changes needed.** The existing `@layer base` setup with `font-sans` on body is correct. DM Serif Display is opt-in via `font-display` class.

**4. Heading.tsx — Apply serif font for display-scale headings:**
Update the `headingVariants` CVA definition. Add `font-display` to levels 1 and 2 so that `text-h1` and `text-h2` headings use DM Serif Display. Levels 3 and 4 remain sans-serif (font-sans or no font override needed since body is already sans):
```tsx
export const headingVariants = cva("tracking-tight text-content", {
  variants: {
    level: {
      1: "text-h1 font-display",
      2: "text-h2 font-display",
      3: "text-h3 font-semibold",
      4: "text-h4 font-semibold",
    },
  },
  defaultVariants: {
    level: 2,
  },
});
```
Remove the top-level `font-semibold` from the CVA base since DM Serif Display at weight 400 should not be forced semibold — it looks wrong with semibold on a display serif. Keep `font-semibold` on levels 3 and 4 which remain Inter.

Note: The `text-display` size class (used in the identity section for team name) will also get `font-display` applied directly in the section component, not through the Heading component, since `text-display` is used with raw elements for the oversized numerals.
