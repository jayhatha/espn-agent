Parameters:
- `allPlayers: PoolPlayer[]`
- `sgpValuesRaw: number[]`
- `input: DraftEngineInput`
- `remainingSlots: Record<string, number>`
- `nameToExternalRank: Map<string, number>`

Returns: `IdealRosterSignal | null`

Implementation:
1. Early return null if `allPlayers.length === 0 || input.leagueCategories.length === 0`
2. Build `adjustedSgpValues` by mapping each player's raw SGP * `computeExternalRankBoost(nameToExternalRank.get(player.normalizedName))` — per locked decision on external rank boost
3. Build locked players from `input.myRoster`: for each DraftedPlayer, find matching PoolPlayer by `normalizeName(drafted.playerName) === player.normalizedName`. Collect `{ player: PoolPlayer, cost: drafted.cost ?? 0 }`. Sum `lockedTotalCost`.
4. Call `optimizeRoster(allPlayers, adjustedSgpValues, input.remainingBudget + lockedTotalCost, remainingSlots, lockedPlayers)` — per research Pitfall 3: pass totalBudget = remainingBudget + lockedCost so optimizer handles subtraction internally
5. Build `IdealRosterPlayer[]` from result.roster: for each player, set `tier = classifyTier(player.dollars)`, `isLocked = lockedNames.has(player.normalizedName)`, `sgpValue = sgpValuesRaw[allPlayers.indexOf(player)] ?? 0`
6. Count anchors (dollars > 20), core (dollars >= 5 and <= 20), value (dollars < 5) — per locked decision on tier thresholds
7. Return `IdealRosterSignal` with all fields

Add helper `classifyTier(dollars: number): "anchor" | "core" | "value"`:
- `dollars > 20` => "anchor"
- `dollars >= 5` => "core"
- else => "value"
