**A. Create `packages/extension/components/IdealRosterPanel.tsx`**

A self-contained React component following the exact same `<details>` pattern used by League Analysis, Nomination Strategy, and Draft Targets sections in EngineInsights.tsx.

Props interface:
```typescript
interface IdealRosterPanelProps {
  idealRoster: IdealRosterSignal | null;
}
```

Import `IdealRosterSignal` from `../lib/engine/types` (or from `../lib/engine`).

Early return null if `idealRoster` is null or `idealRoster.players.length === 0`.

Structure:
1. **Summary line** — Build a tier count string like "2 anchors + 5 core + 11 value" from `idealRoster.anchorCount`, `coreCount`, `valueCount`. Only include non-zero counts. Display this as secondary text next to "Ideal Roster" label in the `<summary>` element. Per Claude's discretion: put the summary in the `<summary>` line itself so the user sees budget shape without expanding.

2. **Player rows** — Map over `idealRoster.players`. Each row shows:
   - Tier badge: small colored pill with tier label. Use these classes per tier (matching the design system tokens from the extension):
     - anchor: `bg-warning-light text-warning` with label "anchor"
     - core: `bg-info-light text-info` with label "core"
     - value: `bg-surface-tertiary text-content-secondary` with label "value"
   - Player name: truncated, `font-semibold text-content` for undrafted players, `text-content-secondary` for locked (already drafted) players. Per locked decision: locked players are visually distinct.
   - Dollar value: right-aligned, `text-content-secondary`, formatted as `$XX`

3. **Unfilled slots notice** — If `idealRoster.unfilledSlots > 0`, show a muted line: "{N} slot(s) unfilled"

4. **Total SGP comparison** — Per Claude's discretion: show total projected SGP at the bottom as a muted metadata line (e.g. "12.4 projected SGP | $237 budget used") for users who want to see the quantitative summary.

CSS classes must match the existing EngineInsights pattern exactly:
- `<details className="group">` (no `open` attribute — collapsed by default per locked decision)
- `<summary className="px-3 py-2 cursor-pointer flex items-center justify-between bg-surface-secondary hover:bg-surface-tertiary/50 select-none border-t border-surface-tertiary">`
- Content wrapper: `<div className="px-3 pb-3 pt-2 bg-surface">`
- Arrow: `<span className="text-body-xs text-content-secondary group-open:rotate-180 transition-transform">&#9662;</span>`
