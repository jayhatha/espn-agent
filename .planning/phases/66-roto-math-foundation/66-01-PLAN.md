  <name>Task 1: Add interpolateRotoPoints() and computeMarginalGains() to shared/formulas.ts</name>
  <files>packages/shared/src/formulas.ts</files>
  <action>
Add two pure functions to the end of packages/shared/src/formulas.ts:

1. **interpolateRotoPoints()** — Takes an array of `{ teamId: number; teamName: string; value: number }` objects and a `direction: "HIGHER_BETTER" | "LOWER_BETTER"`. Sorts teams by value (descending for HIGHER_BETTER, ascending for LOWER_BETTER). Returns `Array<{ teamId: number; teamName: string; rank: number; rotoPoints: number }>` where rotoPoints = numTeams - rank + 1. This mirrors the backend's `rankAndStore` logic in standings-projection.ts (ROTO-02).

2. **computeMarginalGains()** — Takes `myTeamId: number`, a `Map<string, Array<{ teamId: number; teamName: string; value: number }>>` keyed by category_id, and an array of `{ category_id: string; name: string; direction: "HIGHER_BETTER" | "LOWER_BETTER" }`. For each category:
   - Rank all teams using interpolateRotoPoints()
   - Find myTeam's position
   - Find the team immediately above in rank (rank - 1)
   - Compute the absolute gap between my value and theirs
   - Return `MarginalGain[]` sorted by gap ascending (cheapest improvement first)

MarginalGain interface:
```typescript
export interface MarginalGain {
  categoryId: string;
  categoryName: string;
  currentRank: number;
  currentRotoPoints: number;
  teamAbove: { teamId: number; teamName: string; value: number } | null;
  myValue: number;
  gap: number;
  potentialPointsGain: number; // always 1
  direction: "HIGHER_BETTER" | "LOWER_BETTER";
}
```

If team is already rank 1, teamAbove is null and gap is 0.

For rate stats (ERA, WHIP), show the raw rate gap (e.g., gap = 0.15 ERA). Do NOT try to convert to component deltas — that's Phase 67's job per research.

Export both functions and the MarginalGain interface.

  </verify>
