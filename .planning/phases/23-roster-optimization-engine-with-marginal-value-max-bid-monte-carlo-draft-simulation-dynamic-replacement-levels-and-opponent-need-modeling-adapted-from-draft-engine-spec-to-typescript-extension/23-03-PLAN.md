**Extend `types.ts`:**

Add `RosterOptimizationSignal` to the file:
```typescript
export interface RosterOptimizationSignal {
  maxBid: number;
  expectedMarketPrice: number;
  valueSurplus: number;
  shouldBid: boolean;
  topTargets: TargetRecommendation[];
  opponentPressure: Record<string, number>;
  simulationEV: number;
  simulationStdDev: number;
  computeTimeMs: number;
}
```

Add `optimization` field to `DraftEngineSignals`:
```typescript
export interface DraftEngineSignals {
  // ... existing fields unchanged ...
  optimization: RosterOptimizationSignal | null;  // null when no nomination or insufficient data
}
```

**Update `engine/index.ts`:**

1. Add imports for the new modules:
   ```typescript
   import { buildSGPVectors } from "./sgp";
   import { optimizeRoster } from "./roster-optimizer";
   import { computeMaxBid } from "./bid-optimizer";
   import { buildOpponentModel, estimateMarketPrice, computePositionCompetition } from "./opponent-model";
   import { runMonteCarlo } from "./monte-carlo";
   ```

2. Add module-level SGP cache:
   ```typescript
   let cachedSGPVectors: SGPVectors | null = null;
   let sgpCacheKey: number = -1;  // allPicks.length at last computation
   ```

3. Add a `computeRosterOptimization` function (inside index.ts, not a separate file) that:
   a. Builds the available player pool using `buildFgPlayerPool` from archetype.ts pattern (reuse its normalizeName + pool builder, or import if it's exported — if not exported, duplicate the pattern inline). Filter to top 200 by dollar value.
   b. Checks cache: if `sgpCacheKey !== input.allPicks.length`, rebuild SGP vectors via `buildSGPVectors`. Update cache.
   c. Builds opponent model from `input.teamRosters`, `input.allTeamBudgets`, roster slots, `input.allPicks`, and `inflation.inflationFactor`.
   d. If `input.currentAuctionPlayerId` is set, find the nominated player in the available pool. Compute max bid via `computeMaxBid`. Compute expected market price via `estimateMarketPrice`.
   e. Run Monte Carlo with 200 simulations (hardcoded default).
   f. Build top 5 targets: sort available pool by SGP descending, compute max bid for each of the top 5, return as `TargetRecommendation[]`.
   g. Return `RosterOptimizationSignal`.

4. Add step 7 in `computeDraftEngine` (after archetype, before returning):
   ```typescript
   // 7. Roster optimization (SGP-based max bid, Monte Carlo, opponent model)
   let optimization: RosterOptimizationSignal | null = null;
   if (input.leagueCategories.length > 0) {
     try {
       optimization = computeRosterOptimization(input, inflation);
     } catch (e) {
       console.warn("[DraftEngine] Roster optimization failed:", e);
     }
   }
   ```

5. Add `optimization` to the return object.

6. **Roster slot mapping:** The spec's roster (1B, 2B, SS, 3B, C, CI, MI, OF x4, UTIL x3, P x9, BN x5) needs to be derived from `input.rosterSize`. Use the same proportional approach as archetype.ts: `{ C: 1, "1B": 1, "2B": 1, SS: 1, "3B": 1, CI: 1, MI: 1, OF: 4, UTIL: 3, P: 9 }` as the default, adjusting total to match rosterSize if different.

7. **Performance logging:** The existing warn at 300ms applies to the full engine. Keep this. Add a separate `console.debug` log for the roster optimization step time.
