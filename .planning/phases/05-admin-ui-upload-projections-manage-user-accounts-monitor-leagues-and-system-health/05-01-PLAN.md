Create `packages/backend/src/api/admin.ts` with the following endpoints, all protected with `onRequest: [requireAdmin]`:

1. **GET /api/admin/users** — List all users with pagination.
   - Query params: `page` (default 1), `limit` (default 50)
   - Select: id, email, role, display_name, created_at, last_login_at, oauth_provider
   - Order by created_at desc
   - Return `{ users, pagination: { page, limit, total } }`
   - Use `db.fn.countAll().as('count')` for total count

2. **PATCH /api/admin/users/:userId/role** — Toggle user role.
   - Body: `{ role: "user" | "admin" }`
   - Validate role is one of ["user", "admin"], return 400 otherwise
   - Prevent admin from demoting themselves (compare request.user.userId to target userId), return 400 with "Cannot change your own role"
   - Update users table: set role and updated_at
   - Log role change: `request.log.info({ adminId, targetUserId, newRole }, 'User role changed')`
   - Return `{ success: true, userId, role }`

3. **GET /api/admin/stats** — System overview statistics.
   - Query users table for total count
   - Query league table for total count
   - Query projections_run for latest run (order by ingested_at desc, limit 1) — return id, as_of_date, staleness, ingested_at
   - Query league_daily_snapshot for last 7 days: count total snapshots, count degraded snapshots, compute success rate as percentage
   - Return `{ userCount, leagueCount, latestProjection, snapshotStats: { total, healthy, degraded, successRate } }`
   - For 7-day filter: use `snapshot_date >= '${sevenDaysAgo}'` where sevenDaysAgo is computed as `new Date(Date.now() - 7 * 24 * 60 * 60 * 1000).toISOString().split('T')[0]`

4. **GET /api/admin/leagues** — League health summary.
   - For each league, find its most recent snapshot (subquery or left join with max snapshot_date)
   - Select: league.id, league.name, league.espn_league_id, latest snapshot_date, is_degraded, degraded_reasons
   - Derive status: if no snapshot -> "no_snapshot", if is_degraded -> "degraded", else -> "healthy"
   - Return `{ leagues: [...] }`
   - Implementation: Use a CTE or subquery to get max snapshot_date per league_id, then join back to get the full snapshot row.

Rate limit all endpoints: `config: { rateLimit: { max: 60, timeWindow: '1 minute' } }`

Register in `packages/backend/src/index.ts`:
- Import: `import { adminRoutes } from "./api/admin.js";`
- Register: `await server.register(adminRoutes);` after the existing route registrations (near line 139, after streamingRoutes)
