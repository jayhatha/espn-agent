  <action>
1. Rewrite `packages/frontend/src/lib/api.ts`:

   **Remove** `getAuthHeaders()` function entirely (no more Authorization header or localStorage).

   **Update `fetchAPI`**: All requests use `credentials: 'include'` so cookies are sent automatically. Remove the Authorization header logic.

   **Add silent refresh on 401**: When a request gets 401, attempt a POST to `/api/auth/refresh` with `credentials: 'include'`. If refresh succeeds, retry the original request. If refresh fails, redirect to `/login`. Use a mutex pattern to prevent multiple concurrent refresh calls:
   ```typescript
   let refreshPromise: Promise<boolean> | null = null;

   async function tryRefresh(): Promise<boolean> {
     if (refreshPromise) return refreshPromise;
     refreshPromise = (async () => {
       try {
         const res = await fetch(`${API_URL}/api/auth/refresh`, {
           method: 'POST',
           credentials: 'include',
         });
         return res.ok;
       } catch {
         return false;
       } finally {
         refreshPromise = null;
       }
     })();
     return refreshPromise;
   }
   ```

   **Update auth methods** (login, signup, getProfile):
   - `login`: Add `credentials: 'include'` to receive Set-Cookie. Response no longer has `token` field -- just `{ user }`.
   - `signup`: Same -- add `credentials: 'include'`, response is `{ user }`.
   - `getProfile`: Uses `fetchAPI` which already includes credentials.

   **Remove** all `localStorage.getItem('auth_token')` and `localStorage.setItem('auth_token', ...)` references.

2. Rewrite `packages/frontend/src/contexts/AuthContext.tsx`:

   **Remove** all `localStorage` usage (getItem, setItem, removeItem for 'auth_token').

   **Remove** the `storage` event listener (no more cross-tab localStorage sync -- cookies handle this natively).

   **On mount**: Call `api.getProfile()` (which uses cookies). If successful, set user. If fails, user is null (not logged in). No token check needed.

   **login method**: Call `api.login(email, password)` which returns `{ user }`. Set user state. No localStorage.

   **signup method**: Call `api.signup(...)` which returns `{ user }`. Set user state. No localStorage.

   **logout method**: Call `api.logout()` (POST /api/auth/logout with credentials) which clears cookies server-side. Set user to null. Redirect to '/'.

   Add `api.logout()` to the api client if not already there:
   ```typescript
   async logout() {
     await fetch(`${API_URL}/api/auth/logout`, {
       method: 'POST',
       credentials: 'include',
     });
   }
   ```

   **Add auto-refresh timer**: When user is non-null, start a 14-minute interval that calls `/api/auth/refresh` (POST, credentials: include). If refresh fails, clear interval and set user to null. Clean up on unmount.

   **loginWithGoogle / loginWithGitHub**: These redirect to backend -- no change needed (backend sets cookies on callback).
