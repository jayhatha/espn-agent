Pipe Phase 23 roster optimization signals (topTargets, simulationEV, shouldBid, maxBid, opponentPressure) through the narrator pipeline so the AI advisor can reference SGP-based bid recommendations, Monte Carlo simulation confidence, and opponent competition when generating tactical commentary.

Output: Updated NarratorPayload contract (both sides), enriched payload builder, nomination trigger, and LLM prompt sections for optimization signals.
</objective>

     shouldBid: boolean;

     simulationEV: number;

   - Read `signals.optimization` (type `RosterOptimizationSignal | null`)
   - When non-null, map to the compact payload format:
     - `topTargets`: slice first 3 from `signals.optimization.topTargets`, map to `{ playerName, position, sgpValue, maxBid, expectedMarketPrice }`
     - `opponentPressure`: convert `Record<string, number>` to array, sort descending by competition factor, slice first 3, map to `{ position, competitionFactor }`
     - `simulationConfidence`: derive from `simulationStdDev / simulationEV` ratio — `<0.1` = "high", `<0.3` = "medium", else "low". Guard against simulationEV === 0 (return "low")
     - Pass through `shouldBid`, `maxBid`, `valueSurplus`, `simulationEV` directly
   - When null, set `optimization: null`

5. Add nomination trigger in the `useEffect` that watches trigger conditions:

   - Before the existing alert/budget triggers, check if `context.currentAuctionPlayer?.playerName` differs from `prevAuctionPlayerRef.current`
   - If different and non-null, set `triggerReason = "nomination"` and update the ref
   - Note: `currentAuctionPlayer` comes from the draft store (already in scope via `useDraftStore()`)
   - Add `currentAuctionPlayer?.playerName` to the useEffect dependency array
