**Endpoint 1: GET /api/leagues/:leagueId/teams/:teamId/trends/hot-cold**

Query params: `days` (default 7), `season` (optional year).

Logic:
1. Get latest snapshot_date from `league_daily_snapshot` for this league.
2. Get team's current roster from `team_roster_snapshot` for that snapshot_date (player_id, roster_slot, roster_status). Filter to active/bench (exclude IL/NA).
3. Get player names by joining with `player` table.
4. Query `player_period_stats` for these player_ids over the last N days (by snapshot_date >= cutoff date). Each row has `components_json` with stat components (H, AB, HR, R, RBI, SB, BB, HBP, SF, TB for hitters; IP, ER, H as H_P, BB as BB_P, K, W, SV for pitchers).
5. Also query `player_period_stats` for the full season (all rows for these players) to compute season baselines.
6. For each player, aggregate 7-day and season components by summing `components_json` values across rows.
7. Determine if player is a hitter or pitcher based on available components (if AB > 0, treat as hitter; if IP > 0, treat as pitcher).
8. For hitters, compute:
   - 7-day OPS = computeOBP(H, BB, HBP, AB, SF) + computeSLG(TB, AB) using formulas from shared/formulas.ts
   - Season OPS (same formula on season totals)
   - 7-day HR rate = HR / AB (or per game if preferred)
   - `opsRatio` = sevenDayOps / seasonOps (or null if season AB < 20)
   - `hrBurst` = true if 7-day HR >= 3 and 7-day HR rate > 2x season HR rate
   - `trend`: "hot" if opsRatio > 1.25 OR hrBurst; "cold" if opsRatio < 0.75 AND season AB >= 50; "neutral" otherwise
   - `drivingStat`: "OPS surge" if opsRatio > 1.25, "HR burst" if hrBurst (prefer HR burst if both), "OPS decline" if cold
9. For pitchers, compute:
   - 7-day ERA, WHIP, K-rate (K/IP) from components
   - Season ERA, WHIP, K-rate from season components
   - `kSpike` = true if 7-day K-rate > 1.25x season K-rate AND 7-day IP >= 5
   - `trend`: "hot" if 7-day ERA < 0.75 * season ERA OR kSpike; "cold" if 7-day ERA > 1.5 * season ERA AND season IP >= 20; "neutral" otherwise
   - `drivingStat`: "K spike" if kSpike, "ERA drop" if low ERA, "ERA spike" if cold
10. Handle edge cases: if player has < 5 AB (hitter) or < 3 IP (pitcher) in 7-day window, set trend to "insufficient" instead. If no period stats exist at all, return an empty array with a `dataAvailable: false` flag.

Response shape:
```typescript
{
  dataAvailable: boolean;
  snapshotDate: string;
  windowDays: number;
  players: Array<{
    playerId: number;
    playerName: string;
    rosterSlot: string | null;
    rosterStatus: string;
    playerType: "hitter" | "pitcher";
    trend: "hot" | "cold" | "neutral" | "insufficient";
    drivingStat: string | null;
    sevenDay: { ops?: number; era?: number; whip?: number; kRate?: number; hr?: number; sb?: number; ab?: number; ip?: number };
    season: { ops?: number; era?: number; whip?: number; kRate?: number; hr?: number; sb?: number; ab?: number; ip?: number };
    ratios: { opsRatio?: number | null; eraRatio?: number | null; kRateRatio?: number | null };
  }>;
}
```

**Endpoint 2: GET /api/leagues/:leagueId/teams/:teamId/trends/lineup-efficiency**

Query params: `days` (default 7).

Logic:
1. Get latest snapshot_date and compute date range (last N days).
2. Query `player_period_stats` for this team over the date range, including `lineup_slot_id`.
3. For each day (snapshot_date), partition players into active (lineup_slot_id < 20 and not null) and bench (lineup_slot_id >= 20).
4. For each bench player per day, extract HR, SB, and OPS components (H, AB, BB, HBP, SF, TB) from `components_json`.
5. Compare each bench player's daily production to the started player at the same roster_slot (join with `team_roster_snapshot` to match positions). A bench player "outproduced" a starter if bench_HR > starter_HR OR bench_OPS > starter_OPS for that day (compute OPS from components).
6. Handle the position matching: use `team_roster_snapshot.roster_slot` to map players to positions. A bench player's "natural position" comes from their `roster_slot` value; compare to the active player in that same slot.

Response shape:
```typescript
{
  dataAvailable: boolean;
  days: Array<{
    date: string;
    benchProduction: {
      totalHR: number;
      totalSB: number;
      totalOPS: number | null; // computed from summed components
      totalAB: number;
    };
    warnings: Array<{
      benchPlayerId: number;
      benchPlayerName: string;
      starterId: number;
      starterName: string;
      position: string;
      benchStat: { hr: number; ops: number | null };
      starterStat: { hr: number; ops: number | null };
      reason: string; // e.g., "Bench HR: 2 vs Starter HR: 0"
    }>;
  }>;
}
```
