Create `packages/extension/lib/engine/__tests__/auction-sim-spec-targets.test.ts`.

Use vitest (import { describe, it, expect } from "vitest").

Import `runSimulations` from `../auction-sim-harness`.

Run simulations ONCE at module level (outside describe block) to avoid re-running 200 sims per test:
```typescript
const results = runSimulations({ numSimulations: 200 });
```

Set vitest timeout to 120 seconds for this file since simulations take time:
```typescript
describe("auction-sim: spec target verification", { timeout: 120_000 }, () => { ... });
```

**Tests:**

1. **"roster value: mean >= $320"**
   - `expect(results.stats.value.mean).toBeGreaterThanOrEqual(320)`
   - Also log the actual value for debugging: `console.log('Mean roster value:', results.stats.value.mean.toFixed(1))`

2. **"profit: mean >= $70"**
   - `expect(results.stats.profit.mean).toBeGreaterThanOrEqual(70)`
   - Log actual

3. **"top-4 category finishes: rate >= 60%"**
   - `expect(results.stats.top4Rate).toBeGreaterThanOrEqual(0.60)`
   - Also test: `expect(results.stats.avgTop4Count).toBeGreaterThanOrEqual(6)`
   - Log actual

4. **"roto points: mean indicates top-half finish"**
   - In a 13-team, 10-category league, max possible roto points = 130 (rank 1 in every category)
   - Middle-of-pack roto for 13 teams = ~70 points (average finish ~7th in each category = 7 points * 10)
   - Our value strategy should average better than 7th in each category
   - `expect(results.stats.rotoPoints.mean).toBeGreaterThanOrEqual(70)`
   - Log actual

5. **"no simulation has zero profit"**
   - Value strategy should NEVER result in paying more than FG value across all picks
   - `const zeroOrNegativeProfit = results.results.filter(r => r.profit <= 0).length`
   - `expect(zeroOrNegativeProfit).toBeLessThan(results.results.length * 0.1)` — less than 10% of sims have zero/negative profit

6. **"category finish distribution: no category punted in > 50% of sims"**
   - For each category, count sims where we finish last (rank 13)
   - No category should be last-place in more than 50% of sims (balanced strategy)
   - ```
     for (const [cat, ranks] of Object.entries(results.categoryFinishDistribution)) {
       const lastPlaceCount = ranks[12] ?? 0; // rank 13 = index 12
       expect(lastPlaceCount).toBeLessThan(results.results.length * 0.5);
     }
     ```

7. **"player frequency: top drafted players appear in > 30% of sims"**
   - The top 5 most-drafted players should appear in at least 30% of simulations
   - This verifies the strategy consistently targets high-value players
   - `expect(results.playerFrequency[0].pct).toBeGreaterThanOrEqual(0.30)`

**NOTE on test tolerance**: These are statistical tests. If any test is flaky due to randomness, the threshold should be relaxed slightly. Start with the targets above and adjust if needed. The spec targets ($320 value, $70 profit, 60% top-4) are ASPIRATIONAL — if the strategy doesn't meet them, that's a finding about the strategy, not a test bug. Set the test thresholds ~10% below the spec targets to account for simulation variance:
- Value: >= $290 (spec says $320 but sim is approximate)
- Profit: >= $50 (spec says $70)
- Top-4 rate: >= 0.50 (spec says 0.60)
- Roto: >= 65 (above average)

Use these relaxed thresholds in the actual expect() calls. Add comments noting the spec targets for reference.
