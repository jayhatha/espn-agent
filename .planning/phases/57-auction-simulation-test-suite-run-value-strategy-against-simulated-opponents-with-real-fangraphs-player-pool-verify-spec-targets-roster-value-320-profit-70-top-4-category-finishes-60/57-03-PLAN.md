  <action>
Create `tools/simulate-auction.ts` — a standalone CLI script that runs auction simulations and prints formatted results.

**Usage**: `npx tsx tools/simulate-auction.ts [--sims=N] [--temp=T] [--opp-temp=T]`

Parse CLI args from process.argv:
- `--sims=N` (default 200): number of simulations
- `--temp=T` (default 0.15): our team's softmax temperature
- `--opp-temp=T` (default 1.5): opponent temperature
- `--quiet`: suppress per-sim details, only show aggregated results
- `--json`: output results as JSON instead of formatted text

Import `runSimulations` from `../packages/extension/lib/engine/auction-sim-harness`.

**Output format (default text mode):**

```
=== Auction Draft Simulation ===
Config: 200 sims | 13 teams | $260 budget | 28 slots
Our strategy: temp=0.15 (greedy value) | Opponents: temp=1.5

Running simulations... [show progress every 50 sims]

=== AGGREGATED RESULTS ===

Roster Value ($):
  Mean: $XXX | Median: $XXX | P10: $XXX | P90: $XXX
  Spec target: >= $320

Profit ($):
  Mean: $XXX | Median: $XXX | P10: $XXX | P90: $XXX
  Spec target: >= $70

Roto Points:
  Mean: XX.X | Median: XX.X | P10: XX.X | P90: XX.X
  (Max possible: 130 | Average: ~70)

Top-4 Category Finishes:
  Rate: XX.X% of sims had >= 6/10 top-4 finishes
  Avg top-4 count: X.X / 10
  Spec target: >= 60%

=== CATEGORY FINISH DISTRIBUTION ===
Category | Avg Rank | Top-4% | Last%

=== POSITION SPENDING (avg across sims) ===
Hitters: $XXX (XX%)
Pitchers: $XXX (XX%)
(Breakdown: C=$X, 1B=$X, 2B=$X, SS=$X, 3B=$X, OF=$X, SP=$X, RP=$X)

 # | Player            | Drafted% | Avg Cost | FG Value | Position
 1 | Name              |   XX%    |   $XX    |   $XX    | POS
 2 | ...

=== BEST DRAFT ANALYSIS (top quartile by roto) ===

 # | Player            | Appears% | Position
 1 | Name              |   XX%    | POS

[PASS/FAIL] Roster value: $XXX (target: >= $320)
[PASS/FAIL] Profit: $XXX (target: >= $70)
[PASS/FAIL] Top-4 rate: XX% (target: >= 60%)
```

**Implementation details:**
- Parse args with simple string matching (no external arg parser needed)
- Import and call runSimulations with the parsed config
- For progress reporting: if runSimulations doesn't support progress callbacks, just report before/after
- For the "best draft analysis": filter results to top quartile by rotoPoints, then re-compute player frequency for that subset
- For position spending: average the positionSpending records across all sims
- For category finish distribution: compute average rank from the distribution counts
- Format numbers: dollar amounts with $ prefix, percentages with %, roto points to 1 decimal
- Use console.log for all output (not process.stdout.write) for simplicity
- Exit with code 0 on success, 1 if any spec target fails (for CI usage)

**JSON mode**: When --json flag is set, output the full AggregatedResults object as JSON.stringify(results, null, 2) and exit.
