The script must:
1. Strip UTF-8 BOM (`\uFEFF`) from the beginning of each CSV file — confirmed present in the CSVs (PITFALL #3 from RESEARCH.md).
2. Handle quoted CSV fields with embedded commas (player names like `"Witt Jr."` or team names).

**Hitter leaderboard** (`fangraphs-leaderboard-projections-7.csv` -> `fangraphs-leaderboard-hitters.json`):
Extract fields: Name, Team, MLBAMID, PlayerId, HR, R, RBI, SB, AVG, OPS, AB, H, BB, HBP, SF, TB, PA. All numeric fields parsed via `Number()` with `|| 0` fallback.

**Pitcher leaderboard** (`fangraphs-leaderboard-projections-8.csv` -> `fangraphs-leaderboard-pitchers.json`):
Extract fields: Name, Team, MLBAMID, PlayerId, W, SV, HLD, ERA, WHIP, SO, IP, H (as `HA` — hits allowed), ER, BB (as `BBA` — walks allowed), QS, HR (as `HRA` — home runs allowed).
CRITICAL: Pitcher H/BB/HR must be stored as `HA`/`BBA`/`HRA` keys to avoid collision with hitter stat keys when used with `calculateFinalRate` from shared formulas (PITFALL #1 from RESEARCH.md). The shared formula for WHIP uses `HA` and `BBA` keys.

**Hitter auction** (`fangraphs-auction-calculator.csv` -> `fangraphs-auction-hitters.json`):
Extract fields: Name, Team, POS, MLBAMID, PlayerId, Dollars, mAVG, mRBI, mR, mSB, mOPS, PTS. Store `Dollars` as `dollars`, `PTS` as `pts`.

**Pitcher auction** (`fangraphs-auction-calculator-2.csv` -> `fangraphs-auction-pitchers.json`):
Extract fields: Name, Team, POS, MLBAMID, PlayerId, Dollars, mW, mSV, mERA, mWHIP, mSO, PTS, IP. Store `Dollars` as `dollars`, `PTS` as `pts`.

Write compact JSON (no indentation) to minimize extension bundle size. Log the count of converted records for each file.

```typescript
export interface CategoryCeiling {
  stat_key: string;
  currentTotal: number;      // Sum from already-drafted players
  ceilingTotal: number;      // currentTotal + greedy-fill optimal remaining
  competitiveTarget: number; // Top-3 threshold from full player pool
  isPunted: boolean;         // ceiling < 70% of competitive target (or > 130% for LOWER_BETTER)
  direction: "HIGHER_BETTER" | "LOWER_BETTER";
}

export interface PivotPlayer {
  playerId: number;
  playerName: string;
  dollarValue: number;
  category: string;          // The category this player most unlocks
  ceilingLift: number;       // How much the ceiling improves if grabbed
}

export interface BuildArchetypeSignal {
  archetypeLabel: string | null; // e.g. "Power Build", "Pitching-First", null if unclear
  archetypeConfidence: number;   // 0.0-1.0; < 0.5 = show with low-confidence indicator
  picksAnalyzed: number;         // Number of myRoster picks contributing
  ceilings: CategoryCeiling[];
  pivotPlayers: PivotPlayer[];   // Top 3 most impactful available players
  spendingSplit: { hitting: number; pitching: number };
}
```
