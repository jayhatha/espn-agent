  <behavior>
The function `computeBuildArchetype` accepts the user's drafted roster, remaining budget, all draft picks (for determining who is already drafted), FanGraphs projection data (hitters + pitchers), FanGraphs auction value data (hitters + pitchers), league categories, and roster size.

It returns a `BuildArchetypeSignal` containing:
- `ceilings`: Per-category ceiling analysis (current total, greedy-fill ceiling, competitive target, punt status)
- `archetypeLabel`: Classification string or null (< 5 picks)
- `archetypeConfidence`: picks / 10, clamped [0, 1]
- `pivotPlayers`: Top 3 affordable undrafted players that would most improve the weakest ceiling
- `spendingSplit`: Dollars committed to hitting vs pitching

**Test cases (RED phase):**

1. **Empty roster returns null-like signal**: 0 picks analyzed, no ceilings, no label
2. **Single hitter pick**: 1 pick analyzed, ceilings populated for all categories, confidence = 0.1, no archetype label (< 5 picks)
3. **Greedy fill respects budget**: Given a roster with $50 remaining and 5 spots, greedy fill should select players totaling <= $46 ($50 - 4 reserved $1 spots)
4. **Rate stat ceilings use components**: AVG ceiling computed from sum(H)/sum(AB) across roster + filled players, not average of individual AVGs
5. **Punt detection**: When ceiling < 70% of competitive target, `isPunted = true`
6. **Archetype classification with 6 power-heavy picks**: Returns "Power Build" when HR/RBI z-scores > +0.5 and SB z-score < -0.5
7. **Pivot players filtered by affordability**: No pivot player costs more than remainingBudget - (remainingSpots - 1)
8. **Competitive targets computed from player pool**: Top-3 team target = sum of top (roster_slots * 3 / totalTeams) players per category

**Player matching approach:**
Use `normalizeName()` (same logic from `api-client.ts`: NFD decompose, strip diacritics, lowercase, trim) to match drafted player names against FanGraphs projection names. Build a lookup Map keyed by normalized name. Players with no match contribute 0 to team stats (conservative error).

**Greedy fill algorithm:**
1. Build set of drafted player IDs from `allPicks` (by normalized name matching, since FG data uses MLBAMID not ESPN IDs)
2. Merge hitter + pitcher projections with their auction dollar values (match by mlbamId or name)
3. Filter out already-drafted players
4. Sort undrafted players by dollar value descending
5. Reserve $1 per remaining spot (budgetLeft = remainingBudget - (spotsToFill - 1))
6. Greedily fill: take most expensive affordable player, subtract cost, repeat until spotsToFill reached
7. If budget exhausts before all spots filled, use replacement-level stats (zeros) for remaining

**Archetype classification rules:**
- "Power Build": HR z-score > +0.5 AND RBI z-score > +0.5 AND SB z-score < -0.5
- "Speed Build": SB z-score > +1.0 AND HR z-score < 0
- "Pitching-First": pitching $ > 45% of total spent AND at least one pitching z-score > +0.5
- "Balanced": all category z-scores within +/-0.5 of competitive target
- "Stars-and-Scrubs": top player cost > 30% of total budget AND at least 2 categories with z > +0.5 and 2 with z < -0.5
- "OBP/OPS Heavy": OBP or OPS z-score > +0.5 AND HR z-score < 0
- null: fewer than 5 picks (insufficient signal)

Evaluate in order; first match wins. "Balanced" is the fallback for 5+ picks if no other pattern matches.

**Competitive target calculation (per research recommendation — percentile approach):**
For counting stats: sum the category value of the top N players, where N = (hittersPerTeam * totalTeams * 3/totalTeams) = hittersPerTeam * 3 for hitting categories, and pitchersPerTeam * 3 for pitching categories. This represents what a top-3 team could assemble.
For rate stats: compute rate from summed components of the top N players.

**Pivot player identification:**
For each undrafted affordable player, compute how much they'd improve the worst 2-3 category ceilings. Take the player that maximizes ceiling lift in the most-punted or lowest-ratio category. Return top 3 by ceiling lift. Suppress pivot section if no qualified candidates.
