<objective>
Fix the broken opponent model pick-to-position mapping. The current code uses `allPicks.indexOf(pick)` to index into `playerPool`, which maps ESPN picks to FanGraphs pool entries by array position — completely wrong since the orderings are independent. Additionally, `getFilledPositions` has a `return false` that prevents all name matching.

Key insight: `DraftPick` already has `positions: string[]` — we can use `pick.positions` directly instead of looking up in the pool. The `allPicks` parameter in `buildOpponentModel` uses a narrow inline type that omits `positions`; widen it to include `positions` and optionally `playerName`.

Purpose: Fix distorted competitionFactors and teamNeeds that cause wrong market price estimates and bid decisions.
</objective>

     const teamId = pick.teamId;

       teamFilledSlots.set(teamId, new Map());
