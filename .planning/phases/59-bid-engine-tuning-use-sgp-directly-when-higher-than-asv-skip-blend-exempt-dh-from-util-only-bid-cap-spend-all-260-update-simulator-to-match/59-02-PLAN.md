Add at the end of computeOurBid (before `return Math.max(1, bid)`):
```
// Budget flush: spend excess when few slots remain
const slotsLeft = Object.values(team.slotsRemaining).reduce((s, v) => s + v, 0);
const budgetRemaining = team.budget; // team.budget is already remaining budget
const minReserves = Math.max(0, slotsLeft - 1);
const excessBudget = budgetRemaining - minReserves - bid;
if (excessBudget > 0 && slotsLeft <= 5) {
  if (slotsLeft <= 2) {
    bid += excessBudget;
  } else {
    bid += Math.ceil(excessBudget * 0.5);
  }
}
```

Note: In the simulator, `team.budget` is already the remaining budget (starts at 260, decremented each pick). This is simpler than the engine where we compute from hitterSpent + pitcherSpent. The result is equivalent.

const blendedVal = sgpDollars > asv && asv > 0
