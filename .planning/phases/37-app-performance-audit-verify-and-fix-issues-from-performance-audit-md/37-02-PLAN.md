Refactor `writePlayersAndRosters` (lines 440-531) to eliminate the per-player query loop. The current code does 4 queries per player (SELECT existing, INSERT/UPDATE player, conditional INSERT injury_event, INSERT roster_snapshot). With 12 teams x 40 players = ~480 players, that is ~1,920 queries.

**Step 1: Pre-fetch all existing players in one query.**
Before the outer team loop, collect ALL player IDs from all team rosters:
```typescript
const allPlayerIds = teams.flatMap(t => t.roster.map(e => e.espnPlayerId));
```
Then fetch existing players in a single query (guard for empty array):
```typescript
const existingPlayers = allPlayerIds.length > 0
  ? await trx.selectFrom("player").select(["id", "injury_status"]).where("id", "in", allPlayerIds).execute()
  : [];
const existingPlayerMap = new Map(existingPlayers.map(p => [p.id, p.injury_status]));
```

**Step 2: Collect all rows into arrays instead of inserting per-player.**
Build three arrays as you iterate: `playerRows[]`, `injuryEventRows[]`, `rosterSnapshotRows[]`.

For each player in each team:
1. Push to `playerRows` with player data (id, name, mlb_team, positions, injury_status, etc.)
2. Check `existingPlayerMap` for injury status changes. If changed or new player with injury, push to `injuryEventRows`.
3. Push to `rosterSnapshotRows` with (league_id, snapshot_date, team_id, player_id, roster_status, roster_slot, acquisition_type).

**Step 3: Batch insert all rows.**
After the loop:

Players (batch upsert with ON CONFLICT):
```typescript
if (playerRows.length > 0) {
  await trx.insertInto("player").values(playerRows)
    .onConflict(oc => oc.column("id").doUpdateSet({
      name: sql`excluded.name`,
      mlb_team: sql`excluded.mlb_team`,
      positions: sql`excluded.positions`,
      injury_status: sql`excluded.injury_status`,
      injury_updated_at: sql`excluded.injury_updated_at`,
    }))
    .execute();
}
```

Injury events (simple batch insert, no conflict):
```typescript
if (injuryEventRows.length > 0) {
  await trx.insertInto("injury_event").values(injuryEventRows).execute();
}
```

Roster snapshots (batch insert):
```typescript
if (rosterSnapshotRows.length > 0) {
  await trx.insertInto("team_roster_snapshot").values(rosterSnapshotRows).execute();
}
```

This reduces ~1,920 queries to ~4 queries (1 SELECT + 3 batch INSERTs).

if (projectionRows.length > 0) {
