**B-11 (espn.ts lines 22-30):** The current throttle uses a module-level `lastEspnCall` variable. Two concurrent callers can both read the timestamp before either updates it.

1. Install `p-limit`: `pnpm add p-limit --filter backend`
   Note: `p-limit` is ESM-only. The backend uses ESM (check `"type": "module"` in package.json or `tsconfig.json` module resolution). If there are import issues, use `p-limit@5` which is the latest ESM version.

2. Replace the module-level throttle function. Remove:
```typescript
let lastEspnCall = 0;
async function throttleEspnCall() {
  const now = Date.now();
  const timeSinceLastCall = now - lastEspnCall;
  if (timeSinceLastCall < 2000) {
    await new Promise(resolve => setTimeout(resolve, 2000 - timeSinceLastCall));
  }
  lastEspnCall = Date.now();
}
```

Replace with a p-limit based sequential queue that enforces 2-second spacing:
```typescript
import pLimit from "p-limit";

// Serialize all ESPN API calls through a single-concurrency queue
// to prevent concurrent callers from bypassing the 2-second throttle.
const espnThrottle = pLimit(1);
let lastEspnCall = 0;

async function throttledEspnCall<T>(fn: () => Promise<T>): Promise<T> {
  return espnThrottle(async () => {
    const now = Date.now();
    const timeSinceLastCall = now - lastEspnCall;
    if (timeSinceLastCall < 2000) {
      await new Promise(resolve => setTimeout(resolve, 2000 - timeSinceLastCall));
    }
    lastEspnCall = Date.now();
    return fn();
  });
}
```

3. Update ALL callers of `throttleEspnCall()` to use `throttledEspnCall()`. Search for every `await throttleEspnCall()` in the file. Each call site follows the pattern:
```typescript
await throttleEspnCall();
const response = await this.client.get(url, { params, headers });
```
Replace with:
```typescript
const response = await throttledEspnCall(() => this.client.get(url, { params, headers }));
```

Find ALL instances of `throttleEspnCall` in the file and update them. There are likely 4-6 call sites (fetchLeague, fetchFreeAgents, fetchTransactions, fetchPreDraftAuctionValues inner loop, etc.).

The catch block in `fetchPreDraftAuctionValues` that catches 429 is redundant -- it just logs and re-throws, which happens AFTER axios-retry has already exhausted its retries.

Clean up the redundant 429 handling in the try/catch at lines 908-916. Replace:
```typescript
try {
```
