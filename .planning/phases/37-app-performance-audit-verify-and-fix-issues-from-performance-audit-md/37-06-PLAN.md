**B-14 (formulas.ts lines 145-164):** Replace the two-pass variance calculation with single-pass. The current implementation creates an intermediate array with `.map()` then reduces it. Replace `calculateCategorySGP`:
```typescript
export function calculateCategorySGP(
  statValue: number,
  allPlayerValues: number[]
): number {
  if (allPlayerValues.length === 0) return 0;

  const n = allPlayerValues.length;
  let sum = 0;
  let sumSq = 0;
  for (const val of allPlayerValues) {
    sum += val;
    sumSq += val * val;
  }
  const mean = sum / n;
  const variance = sumSq / n - mean * mean;
  const stdDev = Math.sqrt(variance);

  if (stdDev === 0) return 0;

  return (statValue - mean) / stdDev;
}
```
This eliminates the intermediate `squaredDiffs` array allocation and the second array traversal.
