# Plan: Strip Auth & Load ESPN Creds from Env

## Objective

Remove JWT/cookie authentication guards from all API routes and frontend pages so the app works without login. Add env var support for ESPN credentials (ESPN_SWID, ESPN_S2) with encrypted DB fallback.

## Context

- Backend auth middleware: `packages/backend/src/middleware/auth.ts` exports `authenticate`, `requireAdmin`, `requireLeagueAccess`, `requireTeamOwnership`
- These hooks are applied via `onRequest` and `preHandler` on routes in: leagues.ts, recommendations.ts, timeseries.ts, draft.ts, projections.ts, streaming.ts, transaction-impact.ts, lineup.ts, admin.ts, auth.ts
- Frontend: `ProtectedRoute` and `AdminRoute` in `packages/frontend/src/components/ProtectedRoute.tsx` redirect to /login
- Frontend: `AuthContext` checks session on mount, redirects on 401
- Frontend: `api.ts` has 401 intercept that redirects to /login
- ESPN creds currently read from encrypted DB columns (`espn_swid_encrypted`, `espn_s2_encrypted`) via `decryptToken()`
- Strategy: Make middleware no-ops (don't delete files), remove ProtectedRoute wrappers, disable 401 redirects, add env var fallback for ESPN creds

## Tasks

### Task 1: Make backend auth middleware no-ops
type="auto"

**Do:**
- In `packages/backend/src/middleware/auth.ts`, make `authenticate`, `requireAdmin`, `requireLeagueAccess`, `requireTeamOwnership` into no-op async functions that just return (keep the exports, keep the file)
- Add a comment explaining auth is bypassed for single-user mode

**Done when:** All four functions are no-ops. Backend compiles without errors.

### Task 2: Remove frontend auth guards and login redirects
type="auto"

**Do:**
- In `packages/frontend/src/components/ProtectedRoute.tsx`, make `ProtectedRoute` and `AdminRoute` pass-through components (just render children, no auth check)
- In `packages/frontend/src/lib/api.ts`, remove the 401 redirect-to-login logic (keep the retry, just remove the `window.location.href = '/login'` lines and the throw)
- In `packages/frontend/src/contexts/AuthContext.tsx`, make the provider always set a mock user so `useAuth()` never returns null user (avoids breaking components that check `user`)
- In `packages/frontend/src/app/page.tsx`, remove auth-dependent redirect logic -- just redirect to leagues immediately

**Done when:** Frontend compiles. Pages render without redirect to /login.

### Task 3: Add env var ESPN credential support with DB fallback
type="auto"

**Do:**
- Create a utility function `getEspnAuth()` in `packages/backend/src/utils/espn-env.ts` that:
  1. Checks `process.env.ESPN_SWID` and `process.env.ESPN_S2`
  2. If both present, returns `{ SWID, espn_s2 }` from env
  3. If not, returns undefined (caller falls back to DB)
- Update the places that build ESPN auth from DB (leagues.ts, recommendations.ts, projections.ts, admin.ts, player-pool-sync.ts, snapshot-worker.ts, backfill-worker.ts) to try env vars first via `getEspnAuth()`, then fall back to DB decrypt

**Done when:** `getEspnAuth()` utility exists. All ESPN auth sourcing sites try env first. Backend compiles.

### Task 4: Build verification
type="auto"

**Do:**
- Run `pnpm exec tsc --noEmit -p packages/backend/tsconfig.json`
- Run `pnpm exec tsc --noEmit -p packages/frontend/tsconfig.json`
- Fix any type errors

**Done when:** Both projects compile cleanly.
