# Plan 84-01 — Backend: event_source + stat_type enrichment

## Goal

Three backend deliverables:

1. **DB migration**: Add `event_source VARCHAR(20) DEFAULT 'snapshot'` column to `standings_change_event` table.
2. **Agent update**: `StandingsChangeLogAgent.generateEvents()` accepts an `event_source` param; live-poll calls it with `"live"`, snapshot orchestrator calls it with `"snapshot"`.
3. **API filter**: History endpoint (`GET /api/leagues/:id/standings/change-log`) supports optional `?source=live` query param — filters to only `event_source = 'live'` events when provided.

## Tasks

### Task 1: DB migration — add event_source column

**File:** `packages/backend/src/db/migrations/022_add_event_source.sql`

```sql
-- Phase 84: distinguish live-game events from projection-driven snapshot events

ALTER TABLE standings_change_event
  ADD COLUMN IF NOT EXISTS event_source VARCHAR(20) NOT NULL DEFAULT 'snapshot';

CREATE INDEX IF NOT EXISTS idx_sce_source
  ON standings_change_event (league_id, event_source, snapshot_date DESC);

COMMENT ON COLUMN standings_change_event.event_source IS
  'live = generated during live-poll cycle (actual stat change); snapshot = generated from overnight projection diff';
```

### Task 6: Update history API endpoint to support ?source filter

**File:** `packages/backend/src/api/timeseries.ts` (or wherever the change-log history route lives)

Find the `GET /api/leagues/:leagueId/standings/change-log` route. Add optional `source` query param:

```typescript
app.get<{
  Params: { leagueId: string };
  Querystring: { limit?: string; source?: string };
}>(
  "/api/leagues/:leagueId/standings/change-log",
  ...
  async (request, reply) => {
    const { limit, source } = request.query;
    let query = db
      .selectFrom("standings_change_event")
      .selectAll()
      .where("league_id", "=", leagueId)
      .orderBy("occurred_at", "desc")
      .limit(parseInt(limit ?? "50", 10));

    if (source === "live") {
      query = query.where("event_source", "=", "live");
    }

    const events = await query.execute();
    return reply.send({ events });
  },
);
```
