<objective>
Consolidate turn detection in auto-bid-controller.ts to run confirmed-selector strategies (3 and 4) first as the primary tier, and demote UNTESTED strategies (1, 2, 5) to explicit fallbacks. Establish clearNominationState() as the authoritative reset path by ensuring every nomination field goes through it — stop() should not reset nomination fields directly.

Purpose: The 5 parallel strategies have equal priority, meaning an UNTESTED body-text scan or pick-train check can produce a false turn detection before the confirmed Strategy 4 check runs. Consolidating to confirmed-first eliminates this race condition. The clearNominationState/stop() redundancy is a latent bug — if clearNominationState() resets queue state and stop() also resets it directly, they can get out of sync if someone adds a field to only one.

Output: isMyTurnToNominate() with tiered strategy execution, clearNominationState() as single reset path, NominationDiagnostics interface updated with turnStrategyType field.
</objective>

**Fix clearNominationState() to own all nomination state:**

```typescript
private clearNominationState(): void {
  // Clear timer
  if (this.nominationDelayTimer != null) {
    clearTimeout(this.nominationDelayTimer);
    this.nominationDelayTimer = null;
  }
  // Nomination attempt counters
  this.lastNominationTime = null;
  this.nominationAttempts = 0;
  // Diagnostic state
  this.lastAttemptResult = null;
  this.lastCandidateName = null;
  this.lastCandidateSource = null;
  this.lastTurnDetection = {
    matched: false,
    strategy: null,
    strategiesChecked: [],
    turnStrategyType: null, // updated field
  };
  // Queue population state (resets on stop/mode-off so next session starts fresh)
  this.lastQueuePopulateTime = null;
  this.queuedPlayerIds.clear();
}
```
