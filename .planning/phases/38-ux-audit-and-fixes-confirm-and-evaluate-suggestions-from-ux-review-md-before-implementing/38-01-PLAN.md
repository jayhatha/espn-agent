  <name>Task 1: Create BidVerdict consolidated decision card</name>
  <files>packages/extension/components/BidVerdict.tsx, packages/extension/components/DraftSidebar.tsx</files>
  <action>
Create `packages/extension/components/BidVerdict.tsx`:

1. Import `useDraftStore` (for `currentAuctionPlayer`, `remainingBudget`), `useNarratorStore` (for `currentNarration`), and accept `engineSignals: DraftEngineSignals | null` as prop.

2. Return `null` when `currentAuctionPlayer === null` or `engineSignals?.optimization` is falsy.

3. Extract from engineSignals:
   - `maxBid` from `engineSignals.optimization.maxBid`
   - `shouldBid` from `engineSignals.optimization.shouldBid`
   - `expectedMarketPrice` from `engineSignals.optimization.expectedMarketPrice`
   - `winProbability` from `engineSignals.simulation?.winProbability?.winProbability` (optional)

4. Define "risky" state: `shouldBid && (remainingBudget - maxBid < remainingBudget * 0.15)` — bidding would leave budget tight.

5. Border color: green (`border-positive`) for shouldBid and not risky, amber (`border-warning`) for risky, red (`border-negative`) for !shouldBid.

6. Layout (all within a single card, `mx-4 my-2 border-2 rounded-card p-3`):
   - Top row: Large verdict text "BID up to $X" or "PASS" using `text-h4 font-display font-bold`
   - Second row: Two small stat pills side by side: "Market $X" and "Win Prob X%" (if available), using `text-caption` and `bg-surface-tertiary rounded px-2 py-0.5`
   - Third row: One-sentence narrator rationale from `useNarratorStore((s) => s.currentNarration)`, truncated to first sentence (split on '. ' and take index 0 + '.'), styled `text-body-sm text-content-secondary mt-1`

7. Do NOT duplicate data already shown in the Nominated Player Banner above — no player name, no positions. This card is purely the verdict.

8. In `DraftSidebar.tsx`, import BidVerdict and render it:
   - AFTER the Nominated Player Banner section (after the `{/* Nominated Player Banner */}` block closing `</div>`)
   - BEFORE the Auto-Pilot toggle
   - Pass `engineSignals` as prop
   - Wrap in `<ErrorBoundary>`
   - Only render when `draftFormat === "auction"`
