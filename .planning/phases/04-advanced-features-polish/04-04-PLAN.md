Endpoint: `GET /api/leagues/:leagueId/teams/:teamId/lineup/recommendations`
- Auth: `authenticate`, `requireLeagueAccess`, `requireTeamOwnership`
- Query params: `snapshotDate?: string` (default: today's date in YYYY-MM-DD)
- Handler:
  1. Parse leagueId and teamId from params.
  2. If no snapshotDate, get latest from `league_daily_snapshot`.
  3. Instantiate `MLBStatsAPIAdapter(request.log)` and `LineupOptimizerAgent(db, mlbAdapter, request.log)`.
  4. Call `agent.getRecommendations(leagueId, teamId, snapshotDate)`.
  5. Return: `{ recommendations, totalProjectedGain, snapshotDate, isOptimal, generatedAt: new Date().toISOString() }`
- Errors: 404 if no snapshot found, 400 for invalid params.

Endpoint: `GET /api/leagues/:leagueId/streaming-pitchers`
- Auth: `authenticate`, `requireLeagueAccess`
- Query params: `teamId?: string` (for filtering out user's already-rostered), `startDate?: string` (default: today), `lookAheadDays?: string` (default: "7"), `limit?: string` (default: "20")

  1. Parse leagueId, optional teamId.

  4. Return: `{ candidates, dateRange, totalCandidates, generatedAt: new Date().toISOString() }`
- Errors: 404 if no league found, 400 for invalid params.
