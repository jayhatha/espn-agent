**E-12: Consolidate normalizers**

There are 5+ separate `normalizePlayerName`/`normalizeName` implementations across the extension. Two flavors exist:
- NFD-based (draft-state.ts) - removes Jr/Sr suffix, preserves some punctuation
- NFKD-based (content.tsx, AuctionRecommendations, others) - strips ALL non-alphanumeric

The NFKD + strip-all form is more aggressive and better for fuzzy matching. Any name matching under NFD will also match under NFKD.

1. Create `packages/extension/lib/engine/normalizer.ts` as the SINGLE canonical source:
```typescript
/**
 * Canonical player name normalizer for the entire extension.
 * Uses NFKD decomposition + strip all non-alphanumeric for maximal fuzzy matching.
 * This is the ONLY normalization function -- do not create local alternatives.
 */
export function normalizeName(name: string): string {
  return name
    .normalize('NFKD')
    .replace(/[\u0300-\u036f]/g, '')
    .replace(/[^a-zA-Z0-9 ]/g, '')
    .toLowerCase()
    .trim()
    .replace(/\s+/g, ' ');
}
```
