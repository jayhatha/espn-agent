In `auto-bid-controller.ts`:

1. **Import normalizeName** from `./draft-state` — this function strips Jr./Sr., diacritics, collapses whitespace, and lowercases. The function is already exported from draft-state.ts (it's module-level, not inside the store). If it's not exported, export it.

2. **Add a `NominationDiagnostics` interface** to track and expose nomination state:
```typescript
export interface NominationDiagnostics {
  autoMode: boolean;
  currentAuctionPlayer: string | null;
  nominationAttempts: number;
  maxAttempts: number;
  cooldownRemainingMs: number;
  lastAttemptResult: string | null;
  lastCandidateName: string | null;
  lastCandidateSource: 'simulation' | 'idealRoster' | null;
  lastTurnDetectionResult: { matched: boolean; strategy: string | null; strategiesChecked: string[] };
  isActive: boolean; // autoMode && currentAuctionPlayer == null
}
```

3. **Add diagnostic state tracking** to the class: `private lastAttemptResult: string | null = null;`, `private lastCandidateName: string | null = null;`, `private lastCandidateSource: 'simulation' | 'idealRoster' | null = null;`, `private lastTurnDetection: { matched: boolean; strategy: string | null; strategiesChecked: string[] } = { matched: false, strategy: null, strategiesChecked: [] };`

4. **Add `getNominationDiagnostics()` public method** that returns a `NominationDiagnostics` object from current state.

5. **Add `forceNominate()` public method** that resets nominationAttempts to 0, sets lastNominationTime to null (bypass cooldown), and calls `evaluateAndNominate()`. Log `[AutoNominate] Force nominate triggered by user`.

6. **Refactor `isMyTurnToNominate()`** to track which strategies were checked and which matched. Instead of returning `true` at each strategy, set `this.lastTurnDetection = { matched: true, strategy: 'strategy-N-description', strategiesChecked }` before returning. On final `return false`, set `this.lastTurnDetection = { matched: false, strategy: null, strategiesChecked: [...all 5 strategy names...] }`. Log at INFO level which strategy matched: `[AutoNominate] Turn detected via: Strategy 4 (Button--select buttons)`. Log at DEBUG level each strategy check result.

7. **Add structured logging to `evaluateAndNominate()`** at each guard:
   - Entry: `[AutoNominate] evaluateAndNominate() called — autoMode=${autoMode}, auctionPlayer=${currentAuctionPlayer?.playerName ?? 'null'}, attempts=${this.nominationAttempts}/${MAX}, cooldown=${cooldownRemaining}ms`
   - After each guard that returns early: set `this.lastAttemptResult` to the reason (e.g., "autoMode off", "auction active", "max attempts", "cooldown active", "not our turn")
   - After candidate selection: set `this.lastCandidateName` and `this.lastCandidateSource`
   - After ranking lookup: log `[AutoNominate] Ranking lookup: candidateName="${candidateName}" normalized="${normalizedCandidate}" → matched="${matchedRanking?.playerName ?? 'NOT FOUND'}" playerId=${matchedRanking?.playerId ?? 'N/A'}`

8. **Fix the name normalization in ranking lookup** (line ~389-391). Replace the plain `toLowerCase()` comparison with `normalizeName()`:
```typescript
const normalizedCandidate = normalizeName(candidateName);
const matchedRanking = state.rankings?.find(
  (r) => normalizeName(r.playerName) === normalizedCandidate
);
```
This ensures "Vladimir Guerrero Jr." matches "Vladimir Guerrero" and accented names like "Jose Ramirez" (with accent on e) match the ASCII version.

9. **Reset diagnostic state** in `clearNominationState()` and `stop()`.

This lets the user run `espnDraftAssistant.nominationDiag()` in the browser console during a live draft to see exact controller state.
