```typescript
export interface ESPNQueueEntry {
  playerId: number;
  playerName: string;
  position: string;
  queuePosition: number;
}
```

**scrapeESPNNominationQueue() function:**
- Find all `button[data-player-id]` elements in the document
- For each button, check if its `textContent?.trim().toLowerCase()` matches any of: `["dequeue", "deselect", "remove"]` (use `.some(v => text.includes(v))`)
- Skip buttons where text does NOT match any dequeue variant (these are "Queue" or "Select" buttons for non-queued players)
- For matching buttons, extract:
  - `playerId` from `button.getAttribute("data-player-id")` parsed as int
  - `playerName` from the closest row's `a.player-news[title]` attribute (same pattern as `scrapeESPNAuctionTable()`)
  - `position` from the closest row's `.positionPill` textContent (same pattern as `scrapeESPNAuctionTable()`)
  - `queuePosition` incrementing counter (0-based)
- Use `.closest('.fixedDataTableRowLayout_main, [role="row"]')` to find the parent row (same selectors as scrapeESPNAuctionTable uses)
- Return `ESPNQueueEntry[]` (empty array when no queued players found)
- Skip entries with falsy/NaN playerId
- Add a console.log when result has entries: `[ESPN Draft Assistant] scrapeESPNNominationQueue: found ${result.length} queued players`

Place the function and interface AFTER the existing `scrapeESPNAuctionTable()` function and BEFORE `observeCurrentAuctionPlayer()`.
