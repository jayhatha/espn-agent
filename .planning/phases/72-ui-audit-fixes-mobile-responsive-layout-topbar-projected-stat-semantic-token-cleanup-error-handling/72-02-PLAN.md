- bg: `dark:bg-red-900/20`, `dark:bg-amber-900/20`
- border: `dark:border-red-800`, `dark:border-amber-800`
- text: `dark:text-red-400`, `dark:text-amber-400`

For dark-mode-only components (shell pages), use direct classes:
- `text-positive` (resolves to #059669 — works on dark backgrounds)
- `text-negative` (resolves to #dc2626 — works on dark backgrounds)
- `text-warning` (resolves to #d97706 — works on dark backgrounds)

For backgrounds in dark context, use opacity patterns:
- `bg-positive/10` instead of `bg-green-500/10`
- `bg-negative/10` instead of `bg-red-500/10`
- `bg-warning/10` instead of `bg-amber-500/10`

For borders in dark context:
- `border-positive/20` instead of `border-green-500/20`
- `border-negative/20` instead of `border-red-500/20`
- `border-warning/20` instead of `border-amber-500/20`
