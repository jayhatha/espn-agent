# Phase 46 Plan 01: Verify In-Season Pipeline

## Objective

Ensure the daily snapshot pipeline, projected standings, waiver recommendations, and trade analysis work end-to-end for league 112523 after auth stripping (Phase 43) and league defaults (Phase 44).

## Context

- Phase 43 made auth middleware no-op but did NOT populate `request.user` mock -- routes referencing `request.user` will crash
- Phase 43 created `getEspnAuthFromEnv()` in `espn-env.ts` for env var credentials
- Phase 44 created `league-defaults.ts` with hardcoded league 112523 config
- The snapshot endpoint in `leagues.ts` already uses `getEspnAuthFromEnv()` with DB fallback
- The `recommendations.ts` routes already use `getEspnAuthFromEnv()` with DB fallback
- The `authenticate` middleware is no-op but `request.user` is referenced in leagues.ts and projections.ts

## Tasks

### Task 1: Fix auth middleware to populate mock user
type="auto"

The `authenticate` middleware in `middleware/auth.ts` is a no-op but routes still reference `request.user.userId` and `request.user.role`. Fix the middleware to populate a mock user object on the request.

**Done criteria:** `request.user` is populated with a mock admin user in the authenticate middleware.

### Task 2: Fix leagues list endpoint for single-user mode
type="auto"

The `GET /api/leagues` endpoint filters by `request.user.userId` via team.user_id join. In single-user mode, this won't work because teams don't have user_id set. Fix to return all leagues in single-user mode.

**Done criteria:** `GET /api/leagues` returns all leagues without user_id filtering.

### Task 3: Fix projections admin-only check for single-user mode
type="auto"

The projections upload and delete endpoints check `request.user.role !== "admin"`. With mock user as admin, this should work, but verify and ensure it compiles.

**Done criteria:** Projections endpoints compile and mock admin user passes role checks.

### Task 4: Add league bootstrap endpoint
type="auto"

Add a `POST /api/leagues/bootstrap` endpoint that creates league 112523 in the DB if it doesn't exist, using env var ESPN credentials and league defaults. This enables first-time setup without the full connect flow.

**Done criteria:** Bootstrap endpoint creates league row with ESPN league ID 112523, season 2026, and triggers initial snapshot.

### Task 5: TypeScript compilation verification
type="auto"

Run TypeScript compiler on both backend and frontend to verify no type errors.

**Done criteria:** `tsc --noEmit` passes for both packages.

## Verification
