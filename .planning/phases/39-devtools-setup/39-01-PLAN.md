  <action>
    Create .mcp.json at the project root (next to package.json) with the following structure:

    ```json
    {
      "mcpServers": {
        "chrome-devtools": {
          "command": "npx",
          "args": [
            "-y",
            "chrome-devtools-mcp@latest",
            "--browserUrl=http://127.0.0.1:9222"
          ]
        }
      }
    }
    ```

    Key decisions (per research):
    - Use `npx -y chrome-devtools-mcp@latest` — no package.json entry, dev-only, auto-installs on use
    - `--browserUrl=http://127.0.0.1:9222` connects to an existing Chrome instance launched with `--remote-debugging-port=9222`
    - Do NOT add `--user-data-dir` to the MCP args — Chrome is launched separately by the developer with a dedicated profile; the MCP server only connects to the already-running instance
    - Requires Node 20.19+ (project already meets this)

    Verify the JSON is valid (no trailing commas, correct quoting).
  </action>

  <action>
    Create CHROME-PROFILE-SETUP.md documenting the isolated Chrome profile setup. Include all of the following sections:

    ## Why Profile Isolation Matters
    The MCP server connects via CDP (Chrome DevTools Protocol) to any tab in the target Chrome instance. A dedicated profile ensures your real ESPN auth cookies (SWID, espn_s2) in your main Chrome profile are never accessible to the MCP process. The isolated instance has its own cookie jar.

    ## One-Time Setup
    ```bash
    mkdir -p ~/chrome-devtools-profile
    ```

    ## Launch Command (macOS)
    ```bash
    /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
      --remote-debugging-port=9222 \
      --user-data-dir=~/chrome-devtools-profile \
      --no-first-run \
      --no-default-browser-check
    ```
    Log into ESPN Fantasy Baseball in THIS window. Do not use your main Chrome profile.

    ## Verify Remote Debugging is Active
    ```bash
    curl -s http://127.0.0.1:9222/json/version
    ```
    Expected response: JSON object with "Browser" and "webSocketDebuggerUrl" keys.
    If this returns connection refused, Chrome was not started with `--remote-debugging-port=9222`.

    ## ESPN Draft URL Pattern
    ```
    https://fantasy.espn.com/baseball/draft?leagueId=YOUR_LEAGUE_ID
    ```
    Navigate to the draft lobby in the isolated Chrome window and enter the auction draft room before running MCP inspection.

    ## Activate MCP in Claude Code
    Restart Claude Code after .mcp.json is created. The chrome-devtools server will appear in the available tools list. It launches on first use via npx — expect a brief install delay the first time.

    ## iframe Note
    ESPN auction draft pages embed content in iframes. If MCP querySelector calls return 0 results on the main frame, use the MCP's frame-targeting capability to switch to the draft iframe context before running selectors.

    ## Stopping
    Quit the isolated Chrome instance when done. The profile directory persists, so ESPN login is preserved for the next session.
