**Imports:**

**Helper function `priorityBadge(score: number)`:**
Returns `{ label: string; classes: string }`:
- `score >= 0.7` → `{ label: "HIGH", classes: "bg-negative-light text-negative" }`
- `score >= 0.45` → `{ label: "MED", classes: "bg-warning-light text-warning" }`
- `score < 0.45` → `{ label: "LOW", classes: "bg-info-light text-info" }`

These thresholds and color classes match the existing badge pattern in EngineInsights.tsx (lines 48-55, 210-216).

**`PlayerRow` sub-component** (inline, not exported):
- Props: `{ target: PositionTarget }`
- Layout: flex row with `justify-between text-body-xs py-0.5`
- Left side: `target.playerName` with `font-semibold text-content truncate max-w-[100px]`
- Right side: three values in a flex row with `gap-2 text-right shrink-0`:
  1. Max bid: `$${Math.round(target.maxBid)}` in `font-semibold text-content`
  2. Expected market price: `~$${Math.round(target.expectedMarketPrice)}` in `text-content-secondary`
  3. Value surplus: `{surplus >= 0 ? "+" : ""}{surplus}` where surplus = `Math.round(target.valueSurplus)`, colored `text-positive` when >= 0, `text-negative` when < 0

**`PositionGroupSection` sub-component** (inline, not exported):
- Props: `{ group: PositionGroup }`
- Uses native `<details>` (collapsed by default — NO `open` attribute) with `border-t border-surface-tertiary`
- `<summary>` with `py-1.5 cursor-pointer flex items-center justify-between select-none list-none`:
  - Left: position label (`font-semibold text-body-xs text-content`) + priority badge (from `priorityBadge()`) + unfilled slot count (`"N slot(s)"` in `text-body-xs text-content-tertiary`)
  - Right: chevron `▾` in `text-body-xs text-content-secondary`
  - **IMPORTANT pitfall:** Do NOT use `group` class or `group-open:rotate-180` on inner `<details>` — nested group classes interfere with the outer details. Use a plain chevron without rotation animation for inner groups (per research pitfall #6).
- Content: `div.space-y-0.5.pt-1.pb-1` mapping `group.targets` to `<PlayerRow>` components keyed by `target.playerName`

**Main `ShoppingList` export (default):**
- Early return `null` when `shoppingList === null` (null guard per research pitfall #1)
- Outer `<details open className="group">` following the exact same pattern as Inflation section in EngineInsights.tsx (lines 37-61):
  - `<summary>` with `px-3 py-2 cursor-pointer flex items-center justify-between bg-surface-secondary hover:bg-surface-tertiary/50 select-none border-t border-surface-tertiary`
  - Header text: "Shopping List" (`text-body-sm font-semibold text-content`) + position count badge (`positionGroups.length` + "pos" in `text-body-xs text-content-tertiary`, only when `positionGroups.length > 0`)
  - Chevron with `group-open:rotate-180 transition-transform` (safe on outer details since only one `group` class at this level)
- Content `div.px-3.pb-3.pt-1.bg-surface`:
  - When `positionGroups.length === 0`: render `"Roster positions filled"` in `text-body-xs text-content-secondary text-center py-2` (SHOP-05)
  - Otherwise: map `positionGroups` to `<PositionGroupSection>` keyed by `group.position`
  - Do NOT re-sort `positionGroups` — engine already sorts by `priorityScore` descending (SHOP-04)

No new dependencies. No state. No hooks. Pure presentational component.
