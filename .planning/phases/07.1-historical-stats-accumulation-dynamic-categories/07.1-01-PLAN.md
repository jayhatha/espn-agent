<objective>
Fix historical backfill to produce accurate week-by-week standings by switching from team-level cumulative stats (ESPN valuesByStat) to per-period player-level stat accumulation. Add a league categories API endpoint.

Purpose: ESPN's `valuesByStat` returns full-season cumulative totals regardless of `scoringPeriodId`, making all backfilled weeks identical. This fix extracts per-period player stats from `playerPoolEntry.player.stats[]` with `statSplitTypeId=5`, filters active roster (lineupSlotId 0-15), aggregates to team-level, and computes rate stats via component math.

Output: Working per-period stat accumulation in backfill, league categories endpoint, all existing snapshot behavior preserved for live snapshots.
</objective>

**Key implementation detail for rate stats and pitching/batting separation:**

When iterating over a player's stats, determine if the player is a batter or pitcher by checking if they have pitching stats (OUTS/IP/ER) or batting stats (AB/H). ESPN roster entries can be both (two-way players like Ohtani), so accumulate ALL stats for each player.

When computing rate stat values for categories:
- For batting rate stats (AVG, OBP, SLG, OPS): pass the team's accumulated batting components directly — the keys (H, AB, BB, HBP, SF, TB) already match what formulas.ts expects
- For pitching rate stats (ERA, WHIP, K9): build a remapped components object:
  ```typescript
  const pitchingRateComponents = {
    H: teamComponents.HA || 0,   // Hits Allowed -> H for WHIP formula
    BB: teamComponents.BBA || 0, // Walks Allowed -> BB for WHIP formula
    IP: teamComponents.IP || 0,  // Already converted from OUTS
    ER: teamComponents.ER || 0,
    K: teamComponents.K || 0,
  };
  ```
  Then call `calculateFinalRate(formulaId, {}, pitchingRateComponents)`

**How to determine if a category is pitching:** Check if `category.statKey` is in the set `["ERA", "WHIP", "K9", "OUTS", "HA", "BBA", "ER", "K", "W", "L", "SV", "HLD", "QS", "SVO", "BLSV", "CG", "HRA", "WPCT", "K9"]` or more simply, check if `ESPN_STAT_MAP` entry for the category's `espnStatId` >= 34 (all pitching stats in ESPN have stat IDs >= 34).

```typescript
// After executeSnapshot, overwrite standings with per-period player stats
const normalized = this.espnAdapter.normalizeLeagueData(espnData.data);
const categories = normalized.settings.categories;

if (categories.length > 0) {
  // Build espnTeamIdToDbId map
  const espnTeamIdToDbId = new Map<number, number>();
  for (const team of normalized.teams) {
    const dbTeam = await this.db
      .selectFrom("team")
      .select("id")
      .where("league_id", "=", leagueId)
      .where("espn_team_id", "=", team.id)
      .executeTakeFirst();
    if (dbTeam) espnTeamIdToDbId.set(team.id, dbTeam.id);
  }

  // Use raw teams data (not normalized) since we need playerPoolEntry.player.stats[]
  const rawTeams = (espnData.data as any).teams || [];

  await this.db.transaction().execute(async (trx) => {
    await this.snapshotOrchestrator.writeCurrentStandingsFromPlayerStats(
      trx, leagueId, snapshotDate, rawTeams, espnTeamIdToDbId,
      categories, scoringPeriodId,
    );
  });
}
```

```typescript
app.get(
  "/api/leagues/:leagueId/categories",
  {
    onRequest: [authenticate],
    preHandler: [requireLeagueAccess],
  },
  async (request, reply) => {
    const leagueId = parseInt(request.params.leagueId, 10);

    // Get the latest settings version for this league
    const settingsVersion = await db
      .selectFrom("league_settings_version")
      .selectAll()
      .where("league_id", "=", leagueId)
      .orderBy("effective_date", "desc")
      .executeTakeFirst();

    if (!settingsVersion) {
      return reply.code(404).send({ error: "No settings found for this league" });
    }

    const categories = (settingsVersion.settings_json as any).categories || [];
    return { categories };
  },
);
```
