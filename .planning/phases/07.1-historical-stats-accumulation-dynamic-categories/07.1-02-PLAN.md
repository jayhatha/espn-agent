1. Remove the hardcoded `categories` array (lines 192-204):
```typescript

```

2. Add a `useQuery` to fetch league categories:
```typescript
// Fetch league categories for dynamic category dropdown
const { data: categoriesData, isLoading: categoriesLoading } = useQuery({
  queryKey: ["league-categories", leagueId],
  queryFn: () => api.getLeagueCategories(parseInt(leagueId, 10)),
  enabled: !!leagueId,
});
```

3. Derive the categories array from the API response:
```typescript
const categories = (categoriesData?.categories || []).map((cat: any) => ({
  value: cat.stat_key || cat.category_id,
  label: cat.name,
}));
```

4. Update `selectedCategory` default: Instead of hardcoded `"AVG"`, set it dynamically when categories load. Add a `useEffect`:
```typescript
useEffect(() => {
  if (categories.length > 0 && !categories.find((c: any) => c.value === selectedCategory)) {
    setSelectedCategory(categories[0].value);
  }
}, [categories]);
```

Keep the initial state as `useState<string>("")` or `useState<string>("AVG")` — the useEffect will correct it once categories load. Using `"AVG"` as initial is fine since most leagues have AVG and it will be corrected if not.

const isLoading = overallLoading || categoryLoading || projectedLoading || (viewMode === "category" && categoriesLoading);
