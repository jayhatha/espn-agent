**Function 1: `computeReplacementStats`**
```typescript
export function computeReplacementStats(
  undraftedPlayers: PoolPlayer[],
  categories: Category[],
): Record<string, number>
```
For each category, collect stat values from undrafted players (filter v > 0), sort ascending, compute median. Return `Record<stat_key, median_value>`. This represents the "average remaining player" stats.

For rate stats (where `cat.type === "RATE"`): also compute median of the underlying components. Specifically, for rate stat categories, collect all component values (e.g., H, AB for AVG) from undrafted players and compute median per component. Store these as replacement-level components so we can do proper component-based rate calculation later.

Return TWO things from this function (or make it return an object):
- `replacementCounting: Record<string, number>` — median counting stat per category
- `replacementComponents: Record<string, number>` — median of each stat component across undrafted players (H, AB, IP, ER, BB, etc.)

**Implementation detail for components:** Iterate undrafted players. For each player, collect all stat keys. For each component key (H, AB, HR, R, RBI, SB, BB, HBP, SF, TB, PA, IP, ER, HA, BBA, W, SV, HLD, K, SO, QS, HRA), compute the median across players who have that component > 0. Store in `replacementComponents`.

**Function 2: `computeDraftProgressWeight`**
```typescript
export function computeDraftProgressWeight(
  totalPicksMade: number,
  totalPicksInDraft: number,
): number
```
Piecewise linear from research:
- 0% -> 0.0
- 30% -> 0.2
- 50% -> 0.5
- 70% -> 0.85
- 100% -> 1.0

Guard: if totalPicksInDraft === 0, return 0.

**Function 3: `computeRotoPts`**
```typescript
function computeRotoPts(
  teamTotals: Map<string, Record<string, number>>,
  categories: Category[],
): Map<string, { rotoPts: number; categoryRanks: Record<string, number> }>
```
For each category: sort teams by value (HIGHER_BETTER descending, LOWER_BETTER ascending, zero-value teams pushed to bottom). Assign rank points: rank 1 gets N points (where N = total teams), rank N gets 1 point. Also record per-category rank (1-based) for each team. Sum roto points across all categories per team.

**Function 4: `computeProjectedStandings` (main export)**
```typescript
export function computeProjectedStandings(
  teamDraftedTotals: Map<string, Record<string, number>>,
  teamRosters: Map<string, { teamId: string; teamName: string; playerIds: number[] }>,
  allPicks: Array<{ playerId: number; playerName: string; teamId: string }>,
  myTeamId: string | null,
  categories: Category[],
  undraftedPlayers: PoolPlayer[],
  rosterSize: number,
  totalTeams: number,
): ProjectedStandingsSignal
```

Steps:
1. Compute `draftProgressWeight` from `allPicks.length / (totalTeams * rosterSize)`.
2. If fewer than 3 teams in `teamDraftedTotals`, return early with empty signal (stricter than league-analysis's 2-team minimum).
3. Compute replacement-level stats from `undraftedPlayers` via `computeReplacementStats`.
4. For each team in `teamRosters`: compute projected full-season totals by taking their `teamDraftedTotals` and adding replacement-level filler for remaining slots.
   - Count drafted players for this team: `picksByTeam.get(teamId)?.length ?? 0`
   - Remaining slots: `Math.max(0, rosterSize - draftedCount)`
   - For COUNTING categories: `projectedTotal = draftedTotal + (replacementCounting[stat_key] * remainingSlots)`
   - For RATE categories: sum the drafted components + (replacement components * remainingSlots), then call `calculateFinalRate(formula_id, {}, combinedComponents)`. Guard: if IP <= 0, set rate to 0. If result is not finite, set to 0.
   - Teams NOT in teamDraftedTotals (no FG-matched players): use pure replacement-level (replacementCounting * rosterSize for counting, replacement components * rosterSize for rates).
5. Call `computeRotoPts` on the projected totals to get roto points and category ranks per team.
6. Sort teams by projectedRotoPts descending. Assign projectedOverallRank (1-based).
7. Find user's team: identify myWeakCategories (category rank >= totalTeamsWithData - 3, i.e., bottom 4) and myStrongCategories (category rank <= 3, i.e., top 3).
8. Return `ProjectedStandingsSignal` with `performance.now()` timing.

**Key constraints:**
- Pure function: no Zustand, no DOM, no imports from React.
- Rate stat filler MUST use component-based math via `calculateFinalRate`, never average rates.
- Guard against IP <= 0 to prevent NaN/Infinity in ERA/WHIP.
- This function should be efficient: O(teams * categories). No greedy fill per team.
