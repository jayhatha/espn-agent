<objective>
Build the core forward-looking draft simulation engine: a full draft completion simulator that uses softmax-weighted player selection per team, lightweight roto standings computation from completed rosters, and a decision comparison function that runs N simulations per candidate action to produce win probability distributions.

Purpose: Replace the existing single-pick Monte Carlo (SGP-based EV) with standings-based evaluation that captures downstream cascading effects of each decision. This is the algorithmic foundation that Plans 02 and 03 will wire into the engine and UI.

Output: draft-simulator.ts, decision-comparison.ts, extended types in types.ts, and comprehensive tests.
</objective>

```typescript
// ============================================================
// Phase 28: Forward-Looking Draft Simulation types
// ============================================================

export interface SimTeamState {
  budget: number;
  slotsRemaining: Record<string, number>;  // Mutable copy of roster slots
  categoryTotals: Record<string, number>;  // Running stat totals for counting stats
  componentTotals: Record<string, number>; // Running components for rate stats (H, AB, IP, ER, etc.)
}

export interface SimDraftState {
  availableIndices: Set<number>;     // O(1) delete per Phase 23 decision
  teamStates: SimTeamState[];        // One per team
  myTeamIndex: number;               // Which team is "me"
}

export interface SimulationOutcome {
  expectedFinish: number;       // Average final roto rank (1 = first)
  winProbability: number;       // Fraction of sims finishing 1st
  top3Probability: number;      // Fraction finishing top 3
  top6Probability: number;      // Fraction finishing top 6
  expectedRotoPts: number;      // Average roto points
  stdDevRotoPts: number;        // Standard deviation of roto points
  simCount: number;
}

export interface CandidateAction {
  type: "bid" | "pass";
  label: string;                // e.g., "Bid $25 on Soto", "Pass"
  playerIndex?: number;         // Index into PoolPlayer[] for bid actions
  bidPrice?: number;            // Price for bid actions
}

export interface DecisionComparison {
  decisions: Array<{
    label: string;
    outcome: SimulationOutcome;
  }>;
  recommendedAction: string;    // Label of best decision (highest win probability)
  computeTimeMs: number;
}

export interface NominationRecommendation {
  playerIndex: number;
  playerName: string;
  reason: string;
  expectedDrain: number;        // Estimated budget drain on opponents
  trapScore: number;            // 0-1, higher = better trap nomination
}

export interface ForwardSimulationSignal {
  currentDecision: DecisionComparison | null;  // Bid vs pass comparison when player nominated
  winProbability: SimulationOutcome | null;     // Current baseline win probability
  nominationStrategy: NominationRecommendation[] | null;  // Top 3-5 nominations
  computeTimeMs: number;
}
```

**draft-simulator.ts:** Create `packages/extension/lib/engine/draft-simulator.ts` with these exports:

1. `cloneSimState(state: SimDraftState): SimDraftState` - Deep clone without cloning read-only player pool. Use `new Set(state.availableIndices)` and spread operators for team state objects.

2. `draftPlayerToTeam(state: SimDraftState, teamIdx: number, playerIdx: number, players: PoolPlayer[]): void` - Mutates state in-place (called on clones). Removes player from availableIndices, decrements team budget by player.dollars, updates slotsRemaining (find first fitting slot using simplified position matching: dedicated slots first, then flex CI/MI/UTIL/P/BN), increments categoryTotals and componentTotals from player.stats.

3. `softmaxSelect(available: Set<number>, players: PoolPlayer[], sgpValues: number[], team: SimTeamState, temperature: number): number` - Returns index of selected player. Filter candidates by budget (maxSpend = budget - max(0, totalSlots - 1)) and slot fit. Compute composite score = max(0.01, sgp + needBoost). Need boost: for each player position, if team has remaining slots at that position, add 2.0 * slotsRemaining to score. Apply softmax: subtract maxScore for numerical stability, exp((score - maxScore) / temperature), weighted random selection. Return -1 if no candidates. Use top-K filtering (top 15 by SGP) before softmax to stay fast.

4. `computeSimStandings(teamStates: SimTeamState[], categories: Category[]): number[]` - Returns roto points per team (parallel array). For each category: extract counting stat values directly from categoryTotals, compute rate stats from componentTotals using `calculateFinalRate`. Sort and assign roto points (N for rank 1, 1 for rank N). Handle LOWER_BETTER by ascending sort with zero values pushed to bottom. Import `calculateFinalRate` from `@espn-fantasy/shared` and `Category` type.

5. `simulateFullDraft(players: PoolPlayer[], sgpValues: number[], categories: Category[], initialState: SimDraftState, temperature: number): SimDraftState` - Clone state, then round-robin: for each team with slotsRemaining > 0, call softmaxSelect and draftPlayerToTeam. Loop until no team picks (break on full round with zero picks). Return completed state.

**Slot matching in draftPlayerToTeam:** Use this simplified logic (same flex map as monte-carlo.ts):
- For each player position: check dedicated slot first (exact match with slotsRemaining > 0)
- Then flex: 1B/3B can fill CI, 2B/SS can fill MI, hitter positions can fill UTIL, SP/RP can fill P, anything can fill BN
- Decrement the first matching slot

**decision-comparison.ts:** Create `packages/extension/lib/engine/decision-comparison.ts` with these exports:

1. `aggregateOutcomes(myTeamIndex: number, allSimRotoPts: number[][], teamCount: number): SimulationOutcome` - Takes array of per-simulation roto points (allSimRotoPts[sim][team]) and computes: expectedFinish (avg rank), winProbability (fraction rank=1), top3Probability, top6Probability, expectedRotoPts (avg), stdDevRotoPts. Rank computed by counting teams with more roto pts than myTeam.

2. `compareDecisions(candidateActions: CandidateAction[], baseState: SimDraftState, players: PoolPlayer[], sgpValues: number[], categories: Category[], simsPerDecision: number, temperature: number): DecisionComparison` - For each candidate action:
   - Clone baseState
   - If action.type === "bid": call draftPlayerToTeam to lock the player onto myTeam at bidPrice (deduct from budget)
   - If action.type === "pass": remove player from available (opponent gets them — just delete from availableIndices)
   - Run simsPerDecision simulations: for each, call simulateFullDraft on the modified state, then computeSimStandings, collect myTeam's roto points
   - Call aggregateOutcomes to get SimulationOutcome
   - Track computeTimeMs
   - recommendedAction = label of the decision with highest winProbability (tie-break: highest expectedRotoPts)

**Design notes:**
- Use 200 simsPerDecision by default (per research: 300 total, but split across 2 decisions = ~150 each; round up to 200 for robustness)
- Temperature default: 1.0 (per research recommendation)
- For "bid" actions, deduct bidPrice from myTeam's budget and decrement a fitting slot before running simulation
- For "pass" actions, simply remove the player from the available pool (simulates opponent winning them)
