   ```typescript
   import { clsx, type ClassValue } from "clsx";
   ```

1. Replace `globals.css` entirely. Remove: CSS variables for foreground/background, gradient body background, prefers-color-scheme dark block. Replace with:
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;

   @layer base {
     body {
       @apply bg-surface text-content antialiased;
     }

     /* Global focus-visible styles for keyboard accessibility */
     *:focus-visible {
       @apply outline-2 outline-offset-2 outline-accent;
     }

     /* Respect reduced motion preference */
     @media (prefers-reduced-motion: reduce) {
       *,
       *::before,
       *::after {
         animation-duration: 0.01ms !important;
         animation-iteration-count: 1 !important;
         transition-duration: 0.01ms !important;
         scroll-behavior: auto !important;
       }
     }

     /* Skip to content link */
     .skip-to-content {
       @apply sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-[100] focus:bg-accent focus:text-content-inverse focus:px-4 focus:py-2 focus:rounded-lg;
     }
   }
   ```

2. Update `layout.tsx`:

   - Add id="main-content" to the `<main>` element
   - Keep Providers and Navigation as-is (Navigation will be redesigned in Plan 03)
