# Plan 83-01 — Backend: Standings Neighborhood API + Enriched Narrative

## Goal

Two backend deliverables:

1. **`GET /api/leagues/:leagueId/teams/:teamId/standings/neighborhood`** — returns today's overall-points standings for the user's team plus the 2 teams immediately above and 2 below in total roto points.

2. **Enriched `proximate_cause` narrative** in `StandingsChangeLogAgent` — instead of "Player improved HR projections", produce a vivid description based on the actual stat delta (today vs yesterday) computed from `team_daily_category_totals`. E.g. "Led by Mike Trout (2 HRs added today)."

## Context

- `team_daily_overall` has: `league_id`, `snapshot_date`, `team_id`, `overall_points`, `overall_rank`
- `team_daily_projected_overall` has projected equivalents (`projected_overall_points`, `projected_overall_rank`)
- `StandingsChangeLogAgent.buildProximateCause()` currently uses RoS projections to find top player — not actual game deltas
- `team_daily_category_totals` stores actual to-date category totals per team per day (populated by snapshot orchestrator)
- We can compute intraday stat delta by comparing today's `team_daily_category_totals` with yesterday's

### Task 1: Add neighborhood endpoint to `api/timeseries.ts`

**Route:** `GET /api/leagues/:leagueId/teams/:teamId/standings/neighborhood`

**Auth:** `authenticate` + `requireLeagueAccess`

**Logic:**

```typescript
// 1. Get today's date (latest snapshot date for this league)
const latest = await db.selectFrom("league_daily_snapshot")...executeTakeFirst();
const today = latest.snapshot_date;

// 2. Fetch all teams' overall points for today
const allOverall = await db
  .selectFrom("team_daily_overall")
  .innerJoin("team", "team.id", "team_daily_overall.team_id")
  .select(["team_daily_overall.team_id", "team.name", "team_daily_overall.overall_points", "team_daily_overall.overall_rank"])
  .where("team_daily_overall.league_id", "=", leagueId)
  .where("team_daily_overall.snapshot_date", "=", today)
  .orderBy("team_daily_overall.overall_rank", "asc")
  .execute();

// 3. Also fetch projected overall for forward-looking points
const allProjected = await db
  .selectFrom("team_daily_projected_overall")
  .innerJoin("team", "team.id", "team_daily_projected_overall.team_id")
  .select(["team_daily_projected_overall.team_id", "team.name", "team_daily_projected_overall.projected_overall_points", "team_daily_projected_overall.projected_overall_rank"])
  .where("team_daily_projected_overall.league_id", "=", leagueId)
  .where("team_daily_projected_overall.snapshot_date", "=", today)
  .orderBy("team_daily_projected_overall.projected_overall_rank", "asc")
  .execute();

// 4. Find my team's rank
const myEntry = allOverall.find(r => r.team_id === teamId);
if (!myEntry) return reply.code(404).send({ error: "Team not found in today's standings" });

// 5. Slice ±2 neighbors
const myIdx = allOverall.indexOf(myEntry);
const start = Math.max(0, myIdx - 2);
const end = Math.min(allOverall.length - 1, myIdx + 2);
const neighborhood = allOverall.slice(start, end + 1).map(row => ({
  teamId: row.team_id,
  teamName: row.name,
  overallPoints: row.overall_points,
  overallRank: row.overall_rank,
  isMyTeam: row.team_id === teamId,
  projectedPoints: allProjected.find(p => p.team_id === row.team_id)?.projected_overall_points ?? null,
  projectedRank: allProjected.find(p => p.team_id === row.team_id)?.projected_overall_rank ?? null,
}));

return reply.send({ neighborhood, snapshotDate: today });
```

### Task 2: Improve `buildProximateCause` in `standings-change-log.ts`

Replace the existing RoS-projection-based lookup with an actual stat-delta computation:

```typescript
private async buildProximateCause(
  leagueId: number,
  teamId: number,
  categoryId: string,
  categoryName: string,
  snapshotDate: string,
  rotoDelta: number,
): Promise<{ playerName: string; stat: string; value: number; description: string } | null> {
  try {
    // 1. Get today's and yesterday's team category total
    const [todayRow, yesterdayRow] = await Promise.all([
      this.db.selectFrom("team_daily_category_totals")
        .select("value")
        .where("league_id", "=", leagueId)
        .where("team_id", "=", teamId)
        .where("snapshot_date", "=", snapshotDate)
        .where("category_id", "=", categoryId)
        .executeTakeFirst(),
      this.db.selectFrom("team_daily_category_totals")
        .select(["value", "snapshot_date"])
        .where("league_id", "=", leagueId)
        .where("team_id", "=", teamId)
        .where("snapshot_date", "<", snapshotDate)
        .where("category_id", "=", categoryId)
        .orderBy("snapshot_date", "desc")
        .executeTakeFirst(),
    ]);

    const statDelta = todayRow && yesterdayRow
      ? Number(todayRow.value) - Number(yesterdayRow.value)
      : null;

    // 2. Find the top contributor from RoS projections (best available proxy for player attribution)
    const rosterEntries = await this.db
      .selectFrom("team_roster_snapshot")
      .innerJoin("player", "player.id", "team_roster_snapshot.player_id")
      .select(["player.id", "player.name"])
      .where("team_roster_snapshot.league_id", "=", leagueId)
      .where("team_roster_snapshot.team_id", "=", teamId)
      .where("team_roster_snapshot.snapshot_date", "=", snapshotDate)
      .limit(30)
      .execute();

    if (rosterEntries.length === 0) return null;

    const playerIds = rosterEntries.map(r => r.id);
    const latestRun = await this.db
      .selectFrom("projections_run")
      .select("id")
      .where("as_of_date", "<=", snapshotDate)
      .orderBy("as_of_date", "desc")
      .limit(1)
      .executeTakeFirst();

    let topPlayer: string | null = null;
    if (latestRun && playerIds.length > 0) {
      const projections = await this.db
        .selectFrom("player_projection")
        .select(["player_id", "stat_components_json"])
        .where("projections_run_id", "=", latestRun.id)
        .where("player_id", "in", playerIds)
        .execute();

      let topValue = 0;
      for (const proj of projections) {
        const stats = proj.stat_components_json as Record<string, number> | null;
        if (!stats) continue;
        const val = stats[categoryId] ?? 0;
        if (Math.abs(val) > Math.abs(topValue)) {
          topValue = val;
          const entry = rosterEntries.find(r => r.id === proj.player_id);
          topPlayer = entry?.name ?? null;
        }
      }
    }

    // 3. Build vivid description
    const action = rotoDelta > 0 ? "gained" : "lost";
    const deltaStr = statDelta !== null ? Math.abs(statDelta).toFixed(0) : null;

    let description: string;
    if (topPlayer && deltaStr) {
      description = `${topPlayer} led a ${deltaStr}-${categoryName} ${action === "gained" ? "gain" : "drop"} today`;
    } else if (topPlayer) {
      description = `${topPlayer} drove ${categoryName} ${action}`;
    } else if (deltaStr) {
      description = `${deltaStr} ${categoryName} ${action === "gained" ? "added" : "lost"} today`;
    } else {
      description = `${categoryName} projections ${action === "gained" ? "improved" : "declined"}`;
    }

    return {
      playerName: topPlayer ?? "Unknown",
      stat: categoryName,
      value: statDelta ?? 0,
      description,
    };
  } catch {
    return null;
  }
}
```
